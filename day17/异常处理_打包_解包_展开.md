## 1. 异常处理（Exception Handling）

### 1.1 什么是异常

异常（Exception）是程序在运行过程中发生的错误事件。Python 中一切皆对象，异常也不例外——每个异常都是 `BaseException` 的子类实例。

常见的内置异常包括：

| 异常类型           | 触发场景                           |
|-------------------|-----------------------------------|
| `ValueError`      | 传入的值不合法（如 `int("abc")`）   |
| `TypeError`       | 类型不匹配（如 `"a" + 1`）          |
| `KeyError`        | 访问字典中不存在的键                 |
| `IndexError`      | 索引超出序列范围                     |
| `FileNotFoundError` | 尝试打开不存在的文件               |
| `ZeroDivisionError` | 除以零                           |
| `AttributeError`  | 访问对象不存在的属性                 |
| `ImportError`     | 导入模块失败                        |

```python
# 异常会导致程序中断
numbers = [1, 2, 3]
print(numbers[10])  # IndexError: list index out of range
print("这行代码永远不会执行")
```

### 1.2 `try...except` 基础语法

`try...except` 是 Python 异常处理的核心结构。它的基本思想是：**把可能出错的代码放在 `try` 块中，把错误处理逻辑放在 `except` 块中**。

**核心本质：确保程序的健壮性**

```python
try:
    result = 10 / 0
except ZeroDivisionError:
    print("错误：不能除以零！")
    result = 0

print(f"结果是: {result}")  # 输出: 结果是: 0
```

#### 捕获多种异常

```python
def safe_divide(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        print("错误：除数不能为零")
        return None
    except TypeError:
        print("错误：参数必须是数字")
        return None

print(safe_divide(10, 2))    # 5.0
print(safe_divide(10, 0))    # None（捕获 ZeroDivisionError）
print(safe_divide("a", 2))   # None（捕获 TypeError）
```

#### 捕获异常对象

使用 `as` 关键字可以获取异常实例，从而访问更详细的错误信息：

```python
try:
    data = {"name": "Alice"}
    print(data["age"])
except KeyError as e:
    print(f"缺失的键是: {e}")           # 输出: 缺失的键是: 'age'
    print(f"异常类型是: {type(e)}")      # 输出: 异常类型是: <class 'KeyError'>
    print(f"异常参数是: {e.args}")       # 输出: 异常参数是: ('age',)
```

#### 用一个 `except` 捕获多种异常

```python
try:
    value = int("hello")
except (ValueError, TypeError) as e:
    print(f"转换失败: {e}")  # 输出: 转换失败: invalid literal for int() with base 10: 'hello'
```

### 1.3 `try...except...else...finally` 完整结构

Python 提供了四个关键字来构建完整的异常处理流程：

```python
try:
    # 可能出错的代码
    ...
except SomeError:
    # 出错时执行
    ...
else:
    # 没出错时执行（try 块成功时）
    ...
finally:
    # 无论如何都会执行（清理资源）
    ...
```

**实际示例：安全地读取文件**

```python
def read_config(filepath):
    file = None
    try:
        file = open(filepath, "r", encoding="utf-8")
        content = file.read()
    except FileNotFoundError:
        print(f"配置文件不存在: {filepath}")
        return {}
    except PermissionError:
        print(f"没有权限读取文件: {filepath}")
        return {}
    else:
        # 只有在 try 块没有抛出异常时才执行
        print("配置文件读取成功！")
        import json
        return json.loads(content)
    finally:
        # 无论如何都要关闭文件（即使发生了异常）
        if file is not None:
            file.close()
            print("文件已关闭")

# 更好的写法：使用 with 语句（上下文管理器）
def read_config_better(filepath):
    try:
        with open(filepath, "r", encoding="utf-8") as file:
            content = file.read()
    except (FileNotFoundError, PermissionError) as e:
        print(f"读取失败: {e}")
        return {}
    else:
        import json
        return json.loads(content)
    # with 语句自动关闭文件，无需 finally
```

**各块的执行时机总结：**

```
┌─────────────────────────────────────────────┐
│                 try 块执行                    │
│                                             │
│    成功 ──────▶ else 块 ──────▶ finally 块   │
│                                             │
│    失败 ──────▶ except 块 ────▶ finally 块   │
└─────────────────────────────────────────────┘
```

### 1.4 `raise` 主动抛出异常

有时候你需要在自己的代码中主动触发异常，这时候使用 `raise` 关键字：

```python
def set_age(age):
    if not isinstance(age, int):
        raise TypeError("年龄必须是整数")
    if age < 0 or age > 150:
        raise ValueError(f"年龄 {age} 不在合理范围内 (0-150)")
    return age

# 使用
try:
    set_age(-5)
except ValueError as e:
    print(e)  # 输出: 年龄 -5 不在合理范围内 (0-150)
```

#### `raise...from` 异常链

当你捕获一个异常后抛出另一个异常时，可以使用 `from` 保留原始异常的上下文：

```python
class DatabaseConnectionError(Exception):
    """自定义数据库连接异常"""
    pass

def connect_db(host, port):
    try:
        # 模拟底层网络异常
        raise ConnectionRefusedError(f"无法连接到 {host}:{port}")
    except ConnectionRefusedError as e:
        raise DatabaseConnectionError("数据库服务不可用") from e

try:
    connect_db("localhost", 5432)
except DatabaseConnectionError as e:
    print(f"应用层异常: {e}")
    print(f"根因异常: {e.__cause__}")
    # 输出:
    # 应用层异常: 数据库服务不可用
    # 根因异常: 无法连接到 localhost:5432
```

### 1.5 自定义异常类

在实际项目中，自定义异常能让错误语义更清晰、更贴合业务逻辑。自定义异常应继承 `Exception`（而非 `BaseException`）。

```python
class AppError(Exception):
    """应用基础异常"""
    def __init__(self, message, code=None):
        super().__init__(message)
        self.code = code


class ValidationError(AppError):
    """数据校验异常"""
    def __init__(self, field, message):
        super().__init__(f"字段 '{field}' 校验失败: {message}", code=400)
        self.field = field


class AuthenticationError(AppError):
    """认证异常"""
    def __init__(self, message="认证失败，请重新登录"):
        super().__init__(message, code=401)


class NotFoundError(AppError):
    """资源未找到异常"""
    def __init__(self, resource, resource_id):
        super().__init__(f"{resource}(ID={resource_id}) 不存在", code=404)
        self.resource = resource
        self.resource_id = resource_id


# 实际使用
def create_user(data):
    if not data.get("email"):
        raise ValidationError("email", "邮箱不能为空")
    if "@" not in data["email"]:
        raise ValidationError("email", "邮箱格式不正确")
    return {"id": 1, **data}


def get_user(user_id):
    users = {1: "Alice", 2: "Bob"}
    if user_id not in users:
        raise NotFoundError("用户", user_id)
    return users[user_id]


# 统一异常处理
def handle_request(action, **kwargs):
    try:
        if action == "create":
            return create_user(kwargs)
        elif action == "get":
            return get_user(kwargs["user_id"])
    except ValidationError as e:
        print(f"[{e.code}] 校验错误 - {e}")
    except NotFoundError as e:
        print(f"[{e.code}] 未找到 - {e}")
    except AuthenticationError as e:
        print(f"[{e.code}] 认证错误 - {e}")
    except AppError as e:
        print(f"[{e.code}] 应用错误 - {e}")


handle_request("create", email="")          # [400] 校验错误 - 字段 'email' 校验失败: 邮箱不能为空
handle_request("create", email="invalid")   # [400] 校验错误 - 字段 'email' 校验失败: 邮箱格式不正确
handle_request("get", user_id=99)           # [404] 未找到 - 用户(ID=99) 不存在
```

### 1.6 异常处理的最佳实践

```python
# 1. 尽量精确捕获，避免裸 except
# ❌ 不推荐：会吞掉所有异常，包括 KeyboardInterrupt 和 SystemExit
try:
    process_data()
except:
    pass

# ❌ 也不推荐：范围太广
try:
    process_data()
except Exception:
    pass

# ✅ 推荐：精确捕获预期的异常
try:
    process_data()
except (ValueError, KeyError) as e:
    logger.error(f"数据处理失败: {e}")


# 2. 记录异常信息
import logging

logger = logging.getLogger(__name__)

try:
    result = risky_operation()
except SpecificError as e:
    logger.exception("操作失败，详细信息如下")  # exception() 会自动记录堆栈
    raise  # 记录后继续向上抛出


# 3. EAFP vs LBYL
# LBYL (Look Before You Leap) - 先检查再操作
if key in dictionary:
    value = dictionary[key]
else:
    value = default_value

# EAFP (Easier to Ask Forgiveness than Permission) - Pythonic 风格
try:
    value = dictionary[key]
except KeyError:
    value = default_value

# 更简洁的替代方案
value = dictionary.get(key, default_value)


# 4. 不要忽略 finally 中的异常风险
# ❌ finally 中的 return 会吞掉 except 中的异常
def bad_function():
    try:
        raise ValueError("重要错误")
    except ValueError:
        print("捕获到异常")
    finally:
        return "这会吞掉异常"  # 异常被静默忽略

# ✅ 在 finally 中只做清理工作
def good_function():
    try:
        raise ValueError("重要错误")
    except ValueError:
        print("捕获到异常")
        raise  # 让异常继续传播
    finally:
        print("清理资源")  # 只做清理
```

### 1.7 `ExceptionGroup`（Python 3.11+）

Python 3.11 引入了 `ExceptionGroup`，用于同时处理多个异常，这在并发编程中特别有用：

```python
def validate_user(data):
    errors = []

    if not data.get("name"):
        errors.append(ValueError("姓名不能为空"))
    if not data.get("email"):
        errors.append(ValueError("邮箱不能为空"))
    if data.get("age", 0) < 0:
        errors.append(ValueError("年龄不能为负数"))

    if errors:
        raise ExceptionGroup("用户数据校验失败", errors)


try:
    validate_user({"name": "", "email": "", "age": -1})
except* ValueError as eg:
    for err in eg.exceptions:
        print(f"校验错误: {err}")
    # 输出:
    # 校验错误: 姓名不能为空
    # 校验错误: 邮箱不能为空
    # 校验错误: 年龄不能为负数
```

## 2. 打包（Packing）

打包是指将多个值收集到一个容器中。Python 中使用 `*` 和 `**` 运算符在函数参数中实现打包。

### 2.1 `*args` — 位置参数打包

`*args` 将多余的位置参数打包成一个**元组（tuple）**：

```python
def greet(*args):
    print(f"args 类型: {type(args)}")  # <class 'tuple'>
    print(f"args 内容: {args}")
    for name in args:
        print(f"你好, {name}!")

greet("Alice")
# args 类型: <class 'tuple'>
# args 内容: ('Alice',)
# 你好, Alice!

greet("Alice", "Bob", "Charlie")
# args 内容: ('Alice', 'Bob', 'Charlie')
# 你好, Alice!
# 你好, Bob!
# 你好, Charlie!
```

#### 与固定参数混合使用

```python
def log_event(event_type, *details):
    """第一个参数是事件类型，其余参数是事件详情"""
    print(f"事件类型: {event_type}")
    print(f"详情: {details}")

log_event("ERROR", "数据库连接失败", "重试3次后放弃", "已通知管理员")
# 事件类型: ERROR
# 详情: ('数据库连接失败', '重试3次后放弃', '已通知管理员')
```

### 2.2 `**kwargs` — 关键字参数打包

`**kwargs` 将多余的关键字参数打包成一个**字典（dict）**：

```python
def create_profile(**kwargs):
    print(f"kwargs 类型: {type(kwargs)}")  # <class 'dict'>
    print(f"kwargs 内容: {kwargs}")

create_profile(name="Alice", age=30, city="Beijing")
# kwargs 类型: <class 'dict'>
# kwargs 内容: {'name': 'Alice', 'age': 30, 'city': 'Beijing'}
```

#### 与固定参数混合使用

```python
def build_query(table, **conditions):
    """构建 SQL 查询条件"""
    where_clauses = [f"{col} = '{val}'" for col, val in conditions.items()]
    sql = f"SELECT * FROM {table}"
    if where_clauses:
        sql += " WHERE " + " AND ".join(where_clauses)
    return sql


query = build_query("users", name="Alice", age=30, status="active")
print(query)
# SELECT * FROM users WHERE name = 'Alice' AND age = '30' AND status = 'active'
```

### 2.3 参数定义的完整顺序

Python 函数参数定义必须遵循严格的顺序：

```python
def complete_function(
    pos_only,            # 1. 位置参数（仅位置）
    /,                   #    位置参数分隔符（Python 3.8+）
    normal,              # 2. 普通位置/关键字参数
    *args,               # 3. 可变位置参数（打包）
    keyword_only,        # 4. 仅关键字参数
    *,                   #    仅关键字分隔符（当不需要 *args 时使用）
    **kwargs             # 5. 可变关键字参数（打包）
):
    pass


# 实际示例
def register_user(
    username,              # 必须的位置参数
    /,                     # 只能用位置方式传入
    password,              # 普通参数
    *roles,                # 额外的角色（打包为元组）
    email=None,            # 可选的仅关键字参数
    department="general",  # 有默认值的仅关键字参数
    **metadata             # 额外的元数据（打包为字典）
):
    user = {
        "username": username,
        "password": password,
        "roles": roles,
        "email": email,
        "department": department,
        "metadata": metadata,
    }
    return user


user = register_user(
    "alice",                           # username (位置)
    "secret123",                       # password
    "admin", "editor",                 # roles (*args)
    email="alice@example.com",         # email (关键字)
    department="tech",                 # department (关键字)
    phone="13800138000",               # metadata (**kwargs)
    location="Beijing"                 # metadata (**kwargs)
)
print(user)
# {
#     'username': 'alice',
#     'password': 'secret123',
#     'roles': ('admin', 'editor'),
#     'email': 'alice@example.com',
#     'department': 'tech',
#     'metadata': {'phone': '13800138000', 'location': 'Beijing'}
# }
```

## 3. 解包（Unpacking）

解包是打包的逆操作——将容器中的元素拆分并赋值给多个变量。Python 的解包功能极其灵活，远不止简单的元组赋值。

### 3.1 基础解包

```python
# 元组解包
x, y, z = (1, 2, 3)
print(x, y, z)  # 1 2 3

# 列表解包
a, b, c = [10, 20, 30]
print(a, b, c)  # 10 20 30

# 字符串解包
first, second, third = "ABC"
print(first, second, third)  # A B C

# 集合/字典的解包（注意集合无序）
x, y = {1, 2}          # 集合解包
k1, k2 = {"a": 1, "b": 2}  # 字典解包（只取键）
```

### 3.2 星号解包（`*` 捕获剩余元素）

Python 3 引入了带星号的变量，用于捕获解包时的"剩余元素"，这是最强大的解包特性：

```python
# 捕获尾部
first, *rest = [1, 2, 3, 4, 5]
print(first)  # 1
print(rest)   # [2, 3, 4, 5]

# 捕获头部
*init, last = [1, 2, 3, 4, 5]
print(init)  # [1, 2, 3, 4]
print(last)  # 5

# 捕获中间
first, *middle, last = [1, 2, 3, 4, 5]
print(first)   # 1
print(middle)  # [2, 3, 4]
print(last)    # 5

# 星号变量可以是空的
first, *rest = [1]
print(first)  # 1
print(rest)   # []

# 只取首尾
head, *_, tail = range(10)
print(head)  # 0
print(tail)  # 9
# _ 是约定俗成的"不关心"变量名
```

#### 实际应用：处理 CSV 数据

```python
csv_data = """name,email,phone,city,age
Alice,alice@mail.com,13800001111,Beijing,30
Bob,bob@mail.com,13900002222,Shanghai,25
Charlie,charlie@mail.com,13700003333,Shenzhen,28"""

for line in csv_data.strip().split("\n"):
    fields = line.split(",")
    name, email, *extras = fields
    print(f"{name}: {email}, 额外信息: {extras}")

# Alice: alice@mail.com, 额外信息: ['13800001111', 'Beijing', '30']
# Bob: bob@mail.com, 额外信息: ['13900002222', 'Shanghai', '25']
# Charlie: charlie@mail.com, 额外信息: ['13700003333', 'Shenzhen', '28']
```

### 3.3 嵌套解包

Python 支持对嵌套结构进行多层解包：

```python
# 嵌套元组
data = ("Alice", (30, "Beijing"), ["Python", "Java"])
name, (age, city), skills = data
print(f"{name}, {age}岁, 来自{city}, 技能: {skills}")
# Alice, 30岁, 来自Beijing, 技能: ['Python', 'Java']

# 嵌套列表
matrix = [[1, 2], [3, 4], [5, 6]]
(a, b), (c, d), (e, f) = matrix
print(a, b, c, d, e, f)  # 1 2 3 4 5 6

# 复杂嵌套 + 星号
records = [("Alice", 90, 85, 92), ("Bob", 78, 88, 76)]
for name, *scores in records:
    avg = sum(scores) / len(scores)
    print(f"{name}: 平均分 {avg:.1f}")
# Alice: 平均分 89.0
# Bob: 平均分 80.7
```

### 3.4 字典解包

```python
# 使用 ** 解包字典作为函数参数
def connect(host, port, timeout=30, retries=3):
    print(f"连接 {host}:{port} (超时={timeout}s, 重试={retries}次)")

config = {
    "host": "localhost",
    "port": 5432,
    "timeout": 10,
    "retries": 5
}

connect(**config)  # 解包字典为关键字参数
# 连接 localhost:5432 (超时=10s, 重试=5次)
```

## 4. 展开（Spreading）

展开操作使用 `*`（针对可迭代对象）和 `**`（针对字典）将容器中的元素"铺开"。展开和解包在语法上相同，但使用场景有所不同。

### 4.1 `*` 展开可迭代对象

```python
# 函数调用时展开
def add(a, b, c):
    return a + b + c

numbers = [1, 2, 3]
print(add(*numbers))  # 6 — 将列表展开为三个位置参数

# 展开元组
coords = (10, 20)
print(add(*coords, 30))  # 60

# 展开生成器
print(add(*range(1, 4)))  # 6
```

#### 合并可迭代对象

```python
# 合并列表
list1 = [1, 2, 3]
list2 = [4, 5, 6]
list3 = [7, 8, 9]

merged = [*list1, *list2, *list3]
print(merged)  # [1, 2, 3, 4, 5, 6, 7, 8, 9]

# 在合并时添加额外元素
extended = [0, *list1, *list2, 99]
print(extended)  # [0, 1, 2, 3, 4, 5, 6, 99]

# 合并元组
tuple1 = (1, 2)
tuple2 = (3, 4)
merged_tuple = (*tuple1, *tuple2, 5)
print(merged_tuple)  # (1, 2, 3, 4, 5)

# 合并集合
set1 = {1, 2, 3}
set2 = {3, 4, 5}
merged_set = {*set1, *set2}
print(merged_set)  # {1, 2, 3, 4, 5}

# 字符串展开为字符列表
chars = [*"Hello"]
print(chars)  # ['H', 'e', 'l', 'l', 'o']
```

### 4.2 `**` 展开字典

```python
# 合并字典（Python 3.9+ 推荐语法）
defaults = {"theme": "light", "language": "zh-CN", "font_size": 14}
user_prefs = {"theme": "dark", "font_size": 16}

# 方式一：| 运算符（Python 3.9+）
final_config = defaults | user_prefs
print(final_config)
# {'theme': 'dark', 'language': 'zh-CN', 'font_size': 16}

# 方式二：** 展开（兼容所有 Python 3 版本）
final_config = {**defaults, **user_prefs}
print(final_config)
# {'theme': 'dark', 'language': 'zh-CN', 'font_size': 16}

# 注意：后面的字典覆盖前面的同名键
# user_prefs 中的 "theme": "dark" 覆盖了 defaults 中的 "theme": "light"
```

### 4.3 展开的高级应用场景

#### 场景一：构建灵活的函数装饰器

```python
import functools

def log_call(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}({args}, {kwargs})")
        result = func(*args, **kwargs)
        print(f"返回: {result}")
        return result
    return wrapper


@log_call
def calculate(a, b, operation="add"):
    if operation == "add":
        return a + b
    elif operation == "multiply":
        return a * b

calculate(3, 5)
# 调用 calculate((3, 5), {})
# 返回: 8

calculate(3, 5, operation="multiply")
# 调用 calculate((3, 5), {'operation': 'multiply'})
# 返回: 15
```

def process_student(record):
    """处理学生记录：解包 → 计算 → 重组"""
    name, *scores, student_id = record
    avg_score = sum(scores) / len(scores)
    max_score = max(scores)
    min_score = min(scores)

    return {
        "name": name,
        "student_id": student_id,
        "scores": scores,
        "stats": {
            "average": round(avg_score, 2),
            "max": max_score,
            "min": min_score,
            "count": len(scores),
        }
    }


# 批量处理

    ("Alice", 92, 88, 95, 78, "S001"),

    ("Charlie", 95, 98, 92, 96, "S003"),
]

for record in records:

#### 场景四：列表展平（Flatten）

```python
# 嵌套列表展平
nested = [[1, 2, 3], [4, 5], [6, 7, 8, 9]]
flat = [*nested[0], *nested[1], *nested[2]]
print(flat)  # [1, 2, 3, 4, 5, 6, 7, 8, 9]

# 更通用的展平方法
def flatten(lists):
    return [item for sublist in lists for item in sublist]

print(flatten(nested))  # [1, 2, 3, 4, 5, 6, 7, 8, 9]

# 使用 itertools.chain（最高效）
import itertools
flat = list(itertools.chain.from_iterable(nested))
print(flat)  # [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

## 5. 综合实战：打包、解包、展开与异常处理的协作

### 5.1 构建通用的安全调用器

```python
import logging

logger = logging.getLogger(__name__)

def safe_call(func, *args, default=None, **kwargs):
    """
    安全地调用函数，捕获所有异常并返回默认值。
    综合运用了 *args（打包位置参数）和 **kwargs（打包关键字参数）。
    """
    try:
        return func(*args, **kwargs)  # 展开参数
    except Exception as e:
        logger.warning(f"调用 {func.__name__} 失败: {e}")
        return default


# 使用示例
import json

# 安全解析 JSON
result = safe_call(json.loads, '{"name": "Alice"}')
print(result)  # {'name': 'Alice'}

bad_result = safe_call(json.loads, "not a json", default={})
print(bad_result)  # {}

# 安全文件读取
content = safe_call(open, "nonexistent.txt", default="", mode="r")
print(content)  # ""
```

### 5.2 实现一个灵活的配置管理器

```python
class ConfigManager:
    def __init__(self, **defaults):
        self._config = {**defaults}  # 展开并复制默认配置

    def update(self, **overrides):
        """批量更新配置"""
        self._config = {**self._config, **overrides}

    def get(self, key, default=None):
        try:
            return self._config[key]
        except KeyError:
            if default is not None:
                return default
            raise KeyError(f"配置项 '{key}' 不存在且未提供默认值")

    def export(self):
        return {**self._config}  # 返回副本


# 使用
config = ConfigManager(
    database_url="postgresql://localhost:5432/mydb",
    redis_url="redis://localhost:6379",
    debug=False,
    log_level="INFO"
)

# 根据环境变量覆盖
env_overrides = {"debug": True, "log_level": "DEBUG"}
config.update(**env_overrides)

print(config.export())
# {
#     'database_url': 'postgresql://localhost:5432/mydb',
#     'redis_url': 'redis://localhost:6379',
#     'debug': True,
#     'log_level': 'DEBUG'
# }
```

## 6. 速查表

| 语法                | 场景                 | 作用                         | 示例                          |
|--------------------|---------------------|-----------------------------|-------------------------------|
| `*args`            | 函数参数定义          | 打包多余的位置参数为元组        | `def f(a, *args)`             |
| `**kwargs`         | 函数参数定义          | 打包多余的关键字参数为字典      | `def f(a, **kwargs)`          |
| `*iterable`        | 函数调用 / 字面量     | 展开可迭代对象的元素           | `f(*[1,2,3])` / `[*a, *b]`   |
| `**dict`           | 函数调用 / 字面量     | 展开字典为关键字参数           | `f(**{"x": 1})` / `{**a, **b}` |
| `a, *b, c = seq`   | 赋值语句             | 解包序列，星号捕获剩余元素     | `first, *rest = [1,2,3,4]`    |
