# 30 Days of Python 学习项目 🐍

本项目用于记录在 30 天 Python 学习旅程中的代码练习、算法实现与小游戏实战。

## 📁 目录结构

```text
.
├── .gitignore          # Git 忽略文件配置
├── README.md           # 项目自述文档
└── day01/              # 第 1 天：基础与环境熟悉
    ├── test.py         # Python 版本检测与环境测试脚本
    └── guess_number.py # 交互式彩色终端猜数字小游戏
```

---

## 🎮 项目说明与运行指南

### 1. 环境测试脚本 (`day01/test.py`)
该脚本用于检测当前的运行环境，并打印当前激活的 Python 版本。
- **运行命令**：
  ```bash
  python day01/test.py
  ```

### 2. 命令行猜数字小游戏 (`day01/guess_number.py`)
一个采用 ANSI 终端彩色美化设计的交互式猜数字游戏。

#### ✨ 游戏特性：
- **三档难度可选**：
  - 简单：范围 1-50，共 8 次机会。
  - 中等：范围 1-100，共 6 次机会。
  - 困难：范围 1-200，共 4 次机会。
- **生动的生命值显示**：使用心形符号（`❤️` 与 `🖤`）直观呈现剩余机会。
- **健壮的输入校验**：当误输入非数字、或超出难度范围的数字时，给予黄色警告，且**不扣除**宝贵的猜测生命值。
- **游戏时间统计**：通关时展示本次游戏所花费的精确时间。
- **成绩追踪与重玩**：在内存中保存单次运行中各个难度的“历史最佳成绩”（最少猜测次数），通关时对比提醒。支持一键重玩。

- **运行命令**：
  ```bash
  python day01/guess_number.py
  ```
