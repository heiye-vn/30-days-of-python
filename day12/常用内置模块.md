# Python 常用内置模块

## 一、math 模块（高频）

数学运算模块：提供许多数学公式和常量

| 方法/常量                           | 使用场景                                        |
| ----------------------------------- | ----------------------------------------------- |
| `math.ceil(x)` / `math.floor(x)`    | 分页计算、金额向上/向下取整、时间戳对齐         |
| `math.sqrt(x)`                      | 距离计算、向量归一化、几何运算                  |
| `math.log(x)` / `math.log2(x)`      | 数据缩放、信息熵、复杂度分析、dB 转换           |
| `math.pow(x, y)`                    | 指数衰减、复利计算、权重调整                    |
| `math.radians()` / `math.degrees()` | GIS 坐标转换、机器人/游戏角度计算               |
| `math.sin()` / `math.cos()`         | 波形生成、旋转矩阵、周期性信号处理              |
| `math.atan2(y, x)`                  | 计算两点间方位角（比 atan 更安全，避免除零）    |
| `math.hypot(x, y)`                  | 欧氏距离计算（比手动 sqrt(x²+y²) 防溢出）       |
| `math.isclose(a, b)`                | 浮点数比较（**替代 `==`**，避免精度陷阱）       |
| `math.inf` / `math.nan`             | 初始化极值、标记缺失数据、算法哨兵值            |
| `math.gcd()` / `math.lcm()`         | 分数约分、定时任务周期对齐、分辨率适配          |
| `math.prod()`                       | 连乘概率、组合数学计算（替代 functools.reduce） |
| `math.comb()` / `math.perm()`       | 抽样方案数、A/B 测试样本量估算                  |

> [!caution]
>
> 不要用 `math.pow` 做整数幂运算！`2**10` 比 `math.pow(2,10)` 更快且返回 int。`math.pow` 适合浮点指数场景

## 二、random 模块

随机数模块：提供随机数生成

| 方法                              | 典型使用场景                               |
| --------------------------------- | ------------------------------------------ |
| `random.randint(a, b)`            | 验证码生成、随机ID、游戏骰子               |
| `random.choice(seq)`              | 随机抽样、负载均衡选择、A/B 分组           |
| `random.sample(pop, k)`           | 数据集划分（训练/测试集）、抽奖、去重抽样  |
| `random.shuffle(lst)`             | 洗牌、数据打乱（机器学习训练前必做）       |
| `random.random()`                 | 概率判定（`if random() < p`）、权重归一化  |
| `random.uniform(a, b)`            | 超参数搜索、噪声注入、模拟连续变量         |
| `random.gauss(mu, sigma)`         | 模拟测量误差、生成合成数据、蒙特卡洛模拟   |
| `random.choices(pop, weights, k)` | 加权抽奖、按概率采样、马尔可夫链转移       |
| `random.seed(n)`                  | 实验可复现（调试、单元测试、论文复现必备） |
| `random.getrandbits(k)`           | 生成随机 token、临时文件名、分布式 ID 盐值 |

> [!warning]
>
> 涉及密码、Token、密钥、支付等场景，**绝对不要用 random**！必须用 `secrets` 模块

```python
import secrets
secrets.token_hex(16)      # 安全随机 Token
secrets.choice(password_chars)  # 安全随机密码字符
```

## 三、datetime 模块（高频）

日期与时间处理模块：提供日期和时间的解析、格式化及计算功能

| 方法/类/属性                              | 典型使用场景                                           |
| ----------------------------------------- | ------------------------------------------------------ |
| `datetime.datetime.now()`                 | 获取当前本地日期和时间（日志记录、创建时间戳）         |
| `datetime.datetime.utcnow()`              | 获取当前 UTC 日期和时间（跨时区系统推荐）              |
| `datetime.date(year, month, day)`         | 创建日期对象（如账单日、生日等不含具体时间的场景）     |
| `datetime.timedelta(days=...)`            | 时间加减计算（如计算 Token 过期时间、近 7 天数据过滤） |
| `dt.strftime(format)`                     | 日期时间对象格式化为字符串（输出展示、日志打印）       |
| `datetime.datetime.strptime(str, format)` | 字符串解析为日期时间对象（解析用户输入、读取外部数据） |
| `dt.timestamp()`                          | 转换为 UNIX 时间戳（前后端交互、排序、秒级对比）       |
| `datetime.datetime.fromtimestamp(ts)`     | 时间戳转换为本地日期时间                               |

> [!tip]
>
> 现代 Python 开发中，推荐显式指定时区以避免“纯朴时间 (naive datetime)”带来的时区混乱。可以使用 `datetime.timezone.utc` 或 Python 3.9+ 引入的 `zoneinfo` 模块。

```python
from datetime import datetime, timedelta, timezone

# 获取带 UTC 时区的当前时间
now_utc = datetime.now(timezone.utc)
print(now_utc)  # 2026-06-29 03:07:57+00:00

# 计算 3 天后的时间
future_time = now_utc + timedelta(days=3)
```

## 四、pathlib 模块（高频）

面向对象的文件路径操作模块：直观、安全，可跨平台自动处理路径分隔符

| 方法/属性/操作符                          | 典型使用场景                                         |
| ----------------------------------------- | ---------------------------------------------------- |
| `Path.cwd()` / `Path.home()`              | 获取当前工作目录 / 获取用户主目录                    |
| `Path("dir") / "subdir" / "file.txt"`     | 跨平台路径拼接（自动处理 `/` 或 `\`）                |
| `path.exists()`                           | 检查文件或目录是否存在                               |
| `path.is_file()` / `path.is_dir()`        | 判断路径是文件还是目录                               |
| `path.name` / `path.stem` / `path.suffix` | 获取完整文件名、不含后缀的文件名、后缀名             |
| `path.parent`                             | 获取父目录                                           |
| `path.resolve()`                          | 获取绝对路径，消除符号链接和相对路径符号             |
| `path.glob(pattern)` / `path.rglob()`     | 匹配当前/子目录下符合模式的文件（如 `*.py`）         |
| `path.read_text()` / `path.write_text()`  | 快速读取/写入文本（小文件快捷操作，无需显式 `open`） |
| `path.mkdir(parents=True, exist_ok=True)` | 创建多级目录，并自动忽略已存在错误                   |

> [!important]
>
> 尽量使用 `pathlib` 替代旧的 `os.path` 模块。`Path` 对象通过除号 `/` 拼接路径非常优雅，且方法更加直观、安全。

```python
from pathlib import Path

# 获取当前工作目录下的所有 python 文件
current_dir = Path.cwd()
py_files = list(current_dir.glob("*.py"))
```

## 五、json 模块（高频）

JSON 数据的序列化与反序列化模块：Web 开发、API 交互及配置文件解析的基石

| 方法                 | 典型使用场景                                                 |
| -------------------- | ------------------------------------------------------------ |
| `json.dumps(obj)`    | 将 Python 对象转换为 JSON 字符串（网络传输、日志记录）       |
| `json.loads(s)`      | 将 JSON 字符串解析为 Python 对象（解析 API 响应）            |
| `json.dump(obj, fp)` | 将 Python 对象序列化为 JSON 并写入文件（保存配置、导出数据） |
| `json.load(fp)`      | 从文件读取并解析 JSON 数据（读取本地配置）                   |

> [!note]
>
> 序列化中文时，使用 `json.dumps(data, ensure_ascii=False, indent=4)` 可以保留中文不被转义为 Unicode 编码，并且带有缩进，更易阅读。

```python
import json

data = {"name": "张三", "age": 18}
# 序列化为美化的中文 JSON 字符串
json_str = json.dumps(data, ensure_ascii=False, indent=4)
print(json_str)

# 反序列化为 Python 对象
data_parsed = json.loads(json_str)
print(data_parsed["name"])  # 输出: 张三
```

## 六、os 模块（高频）

操作系统交互模块：提供文件系统操作、环境变量管理及系统信息获取等功能。

| 方法/属性/操作                          | 典型使用场景                                                 |
| --------------------------------------- | ------------------------------------------------------------ |
| `os.getcwd()`                           | 获取当前工作目录（确定相对路径基准）                         |
| `os.listdir(path)`                      | 列出指定目录下的所有文件和子目录                             |
| `os.mkdir(path)` / `os.makedirs(path)`  | 创建单级目录 / 创建多级目录（如果父目录不存在会自动创建）    |
| `os.remove(path)` / `os.rmdir(path)`    | 删除文件 / 删除空目录                                        |
| `os.rename(src, dst)`                   | 重命名或移动文件/目录                                        |
| `os.environ.get(key)`                   | 安全获取系统环境变量（常用于读取配置、敏感密钥）             |
| `os.path.join(path, *paths)`            | 跨平台拼接路径（自动根据操作系统使用 `/` 或 `\`）            |

> [!important]
>
> 处理路径时，虽然 `os.path` 仍然可用，但**强烈建议优先使用 `pathlib`**。对于进程控制、环境变量读取（如 `os.environ`），`os` 模块依然是不可替代的。

```python
import os

# 1. 获取并设置环境变量（配置管理的核心）
db_host = os.environ.get("DB_HOST", "localhost")
print(f"数据库地址: {db_host}")

# 2. 遍历目录下的所有文件
current_dir = os.getcwd()
print(f"当前目录: {current_dir}")
for item in os.listdir(current_dir):
    if os.path.isfile(os.path.join(current_dir, item)):
        print(f"文件: {item}")
```

## 七、sys 模块（高频）

运行时系统交互模块：提供与 Python 解释器及其环境交互的接口，常用于获取命令行参数、控制程序退出及修改模块搜索路径。

| 方法/属性/操作                          | 典型使用场景                                                 |
| --------------------------------------- | ------------------------------------------------------------ |
| `sys.argv`                              | 命令行参数列表（`sys.argv[0]` 是脚本名，之后是传递的参数）    |
| `sys.exit(code)`                        | 退出程序（`code=0` 表示正常退出，其他值表示异常退出）         |
| `sys.path`                              | 模块搜索路径的列表（可动态追加 `sys.path.append()` 引入自定义包） |
| `sys.platform`                          | 获取当前操作系统平台（如 `'win32'`, `'darwin'`, `'linux'`）  |
| `sys.version`                           | 获取当前 Python 解释器的版本信息                             |
| `sys.getsizeof(obj)`                    | 获取对象占用的内存字节数（优化内存占用时常用）               |

> [!tip]
>
> 在编写需要接收外部参数的脚本时，`sys.argv` 是最轻量的方式。如果命令行参数非常复杂，推荐使用第三方库 `click` 或内置的 `argparse`。

```python
import sys

# 1. 获取 Python 版本与平台信息
print(f"Python 版本: {sys.version}")
print(f"当前平台: {sys.platform}")

# 2. 处理命令行参数
if len(sys.argv) < 2:
    print("提示: 请提供至少一个命令行参数！")
else:
    # 打印所有命令行参数
    print("接收到的命令行参数:")
    for index, arg in enumerate(sys.argv):
        print(f"参数 {index}: {arg}")
```

## 八、shutil 模块（高频）

高级文件操作模块：提供比 `os` 模块更强大的文件和目录高层操作，包括复制、移动、删除（递归）以及归档压缩。

| 方法/属性/操作                          | 典型使用场景                                                 |
| --------------------------------------- | ------------------------------------------------------------ |
| `shutil.copy(src, dst)`                 | 复制文件内容和权限到目标位置                                 |
| `shutil.copytree(src, dst)`             | 递归复制整个目录树（常用于数据或项目备份）                   |
| `shutil.move(src, dst)`                 | 移动或重命名文件/目录（可跨磁盘分区移动）                     |
| `shutil.rmtree(path)`                   | 递归删除目录及其下所有文件（非常危险，需谨慎使用）           |
| `shutil.make_archive(base_name, format, root_dir)` | 创建压缩归档文件（支持 `'zip'`, `'tar'`, `'gztar'` 等）       |
| `shutil.disk_usage(path)`               | 获取磁盘空间使用情况（返回 total, used, free 字节数）        |

> [!caution]
>
> `shutil.rmtree()` 在删除目录时**不会放入回收站**，而是直接从物理磁盘上抹去。执行此操作前务必进行路径存在性及安全校验！

```python
import shutil

# 1. 查看当前磁盘使用情况
usage = shutil.disk_usage(".")
total_gb = usage.total / (1024 ** 3)
free_gb = usage.free / (1024 ** 3)
print(f"磁盘总空间: {total_gb:.2f} GB, 剩余空间: {free_gb:.2f} GB")
```

## 九、string 模块（常用）

字符串处理辅助模块：提供常用的字符集合常量（如数字、字母、标点符号）及高级字符串模板格式化工具

| 常量/方法/类 | 典型使用场景 |
| --- | --- |
| `string.ascii_letters` | 所有英文大小写字母（`a-zA-Z`），常用于生成随机用户名、验证码 |
| `string.ascii_lowercase` / `string.ascii_uppercase` | 所有小写字母（`a-z`） / 所有大写字母（`A-Z`） |
| `string.digits` | 字符串数字 `0-9`，常用于数字验证码或字符过滤 |
| `string.hexdigits` / `string.octdigits` | 十六进制字符（`0-9a-fA-F`） / 八进制字符 |
| `string.punctuation` | 所有英文标点符号，常用于密码强度校验（是否包含特殊字符） |
| `string.printable` | 所有可打印字符（字母、数字、标点符号、空白符） |
| `string.Template` | 模板字符串，提供比 `f-string` 更安全、适合用户输入渲染的格式化方式（防注入） |

> [!tip]
>
> 许多开发者在需要生成大小写字母时，会手动写 `"abcdefg..."`。**推荐使用 `string.ascii_letters`**，这更安全、不易出错，且代码更具可读性。

```python
import string
import random

# 快速生成一个包含字母、数字和标点符号的 16 位强密码
characters = string.ascii_letters + string.digits + string.punctuation
secure_password = "".join(random.sample(characters, 16))
print(secure_password)
```

### 💡 重点：`string.Template` 进阶与安全对比

`string.Template` 提供了一种更简单、更安全的字符串格式化方式。与 `str.format()` 和 `f-string` 相比，它有两个主要优势：
1. **防止模板注入攻击**：在 Web 应用程序中，如果允许用户自定义输出模板（例如自定义邮件格式），使用 `str.format()` 极易受到注入攻击，因为用户可以通过属性链（如 `{user.password}`）读取敏感数据。而 `string.Template` 严格限制了占位符只能在传入的字典中查找，无法访问对象属性。
2. **格式简单直观**：使用类似 Shell 的 `$` 语法（如 `$name` 或 `${name}`），更易于非技术人员（如运营人员）编写模板。

```python
from string import Template

# 1. 基础用法：动态渲染
template_str = "你好，$name！欢迎来到 $site。"
t = Template(template_str)
result = t.substitute(name="张三", site="Python 30 天训练营")
print(result)  # 输出: 你好，张三！欢迎来到 Python 30 天训练营。

# 2. 安全替换：防止缺失键（Key）导致程序崩溃
# 如果使用 substitute() 且字典中缺少对应的键，会抛出 KeyError 异常。
# 而使用 safe_substitute() 时，缺失的占位符会保留原样，避免系统崩溃。
t2 = Template("邮件发送给 $email，验证码为 $code")
print(t2.safe_substitute(email="user@example.com"))  # 输出: 邮件发送给 user@example.com，验证码为 $code

# 3. 安全性对比（防注入演示）
class User:
    def __init__(self, username, token):
        self.username = username
        self.token = token  # 敏感的 Token

user = User("Alice", "secret_token_123456")

# 危险做法：如果模板内容来自不受信任的用户输入，使用 format() 会暴露敏感数据
unsafe_template = "你好 {user.username}，你的敏感 Token 是 {user.token}"  # 恶意用户可以通过模板刺探 user 对象的任何属性
# print(unsafe_template.format(user=user)) # 如果 user 传进去，会导致 token 被解析出来

# 安全做法：string.Template 无法访问对象属性，仅支持显式传入的键值对
safe_template = Template("你好 $username")
print(safe_template.substitute(username=user.username))  # 无法通过模板访问到 user.token
```

## 十、logging 模块（高频）

日志处理模块：用于替代 `print` 输出，支持将日志分级记录并定向输出到控制台或日志文件

| 方法/级别                  | 典型使用场景                                             |
| -------------------------- | -------------------------------------------------------- |
| `logging.basicConfig(...)` | 配置日志输出格式、级别和输出目标（文件或终端）           |
| `logging.debug(msg)`       | 调试级日志（记录极其详尽的程序运行过程细节）             |
| `logging.info(msg)`        | 信息级日志（记录常规运行信息，如启动、停止、任务成功）   |
| `logging.warning(msg)`     | 警告级日志（记录非致命异常，如配置缺失使用默认值）       |
| `logging.error(msg)`       | 错误级日志（记录发生了严重问题，导致某个功能不可用）     |
| `logging.critical(msg)`    | 严重错误日志（导致整个系统崩溃的毁灭性灾难）             |
| `logging.getLogger(name)`  | 获取一个命名的日志记录器（方便在不同模块中区分日志来源） |

> [!important]
>
> 生产环境项目应始终使用 `logging` 并将其输出级别设为 `INFO` 或 `WARNING`。严禁在生产中输出大量 `DEBUG` 日志，也不要在生产中使用 `print()` 充当日志。

```python
import logging

# 全局配置日志，设置级别为 INFO，格式包含时间和日志级别
logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s - %(levelname)s - %(message)s"
)

logging.info("系统初始化完成...")
logging.warning("磁盘空间少于 10%！")
```

## 十一、typing 模块（高频）

类型提示支持模块：提供丰富的类型注解工具，提高代码在开发阶段的可读性与健壮性

| 类型/类                            | 典型使用场景                                                         |
| ---------------------------------- | -------------------------------------------------------------------- | -------------- |
| `List[T]` / `Dict[K, V]`           | 注解列表与字典（如 `List[int]`，Python 3.9+ 也可用内置 `list[int]`） |
| `Optional[T]`                      | 表示变量可能是 `T` 类型，也可能是 `None`（如 `Optional[str]`）       |
| `Union[T1, T2]`                    | 表示变量可以是多种类型之一（Python 3.10+ 可用 `T1                    | T2` 语法代替） |
| `Any`                              | 允许任意类型，相当于关闭该位置的静态类型检查                         |
| `Callable[[ArgTypes], ReturnType]` | 注解可调用对象（如函数指针、Lambda）                                 |
| `Tuple[T1, T2]`                    | 注解固定长度和特定元素类型的元组                                     |

> [!tip]
>
> 合理使用类型提示配合 IDE（如 PyCharm/VS Code），可以获得极其精准的智能代码补全。它配合 `mypy` 可以在编译前发现绝大多数潜在的类型错误。

```python
from typing import List, Optional, Union

def find_user(user_id: int) -> Optional[dict]:
    # 返回类型可能是字典，也可能是 None
    if user_id == 1:
        return {"name": "Alice"}
    return None

def process_data(data: Union[List[int], str]) -> None:
    # 接收参数可以是整数列表，也可以是字符串
    pass
```

## 十二、decimal 模块（高频）

十进制定点数与浮点数数学运算模块：提供不受浮点数精度限制的高精度计算

| 类/常量                        | 典型使用场景                                                  |
| ------------------------------ | ------------------------------------------------------------- |
| `Decimal(string)`              | 创建高精度数值（**必须使用字符串传参**，如 `Decimal('0.1')`） |
| `getcontext().prec`            | 设定全局计算精度（有效数字位数）                              |
| `ROUND_HALF_UP` / `ROUND_DOWN` | 控制四舍五入模式（金融中常用于精确截断和进位）                |

> [!caution]
>
> 实例化 `Decimal` 时，**切勿使用浮点数传参**！例如 `Decimal(0.1)` 依旧会带有浮点数本身的精度误差。必须写成 `Decimal("0.1")`。

```python
from decimal import Decimal

# 浮点数精度漏洞
print(0.1 + 0.2)  # 输出: 0.30000000000000004

# Decimal 完美解决精度问题
price = Decimal("0.1") + Decimal("0.2")
print(price)      # 输出: 0.3
```

## 十三、hashlib 与 secrets 模块（高频）

安全哈希与密码学安全随机数生成模块：提供安全加密、摘要校验与 Token 生成功能

| 模块.方法/类               | 典型使用场景                                                      |
| -------------------------- | ----------------------------------------------------------------- |
| `hashlib.md5(data)`        | 计算 MD5（常用于快速校验文件完整性，不建议用于存储密码）          |
| `hashlib.sha256(data)`     | 计算安全散列值（目前主流的防篡改签名与摘要算法）                  |
| `secrets.token_bytes(n)`   | 生成 `n` 字节的加密安全随机二进制数据                             |
| `secrets.token_hex(n)`     | 生成长度为 `2*n` 的加密安全随机十六进制字符串（如 Token）         |
| `secrets.token_urlsafe(n)` | 生成适合嵌入 URL 路径的安全 Base64 随机文本                       |
| `secrets.choice(seq)`      | 从序列中返回安全的随机元素（替代 `random.choice` 用于验证码生成） |

> [!important]
>
> 绝对不要用 `hashlib.md5` 存储密码（容易受到彩虹表攻击）。存储用户密码应使用专业的哈希库（如 `bcrypt` 或自带的 `hashlib.pbkdf2_hmac` 并加入随机盐）。

```python
import hashlib
import secrets

# 计算字符串的 SHA256 哈希
sha = hashlib.sha256()
sha.update("my_secure_data".encode("utf-8"))
print(sha.hexdigest())

# 生成安全的重置密码 Token
reset_token = secrets.token_urlsafe(32)
print(reset_token)
```

## 十四、contextlib 模块（高频）

上下文管理器实用工具模块：简化 `with` 语句的自定义过程，帮助优雅、安全地管理系统资源

| 方法/装饰器             | 典型使用场景                                                                             |
| ----------------------- | ---------------------------------------------------------------------------------------- |
| `@contextmanager`       | 使用生成器包装函数，快速创建自定义上下文管理器，免去写类和 `__enter__`/`__exit__` 的繁琐 |
| `closing(thing)`        | 自动在 `with` 退出时调用对象的 `close()` 方法（如包装无 `with` 支持的连接）              |
| `suppress(*exceptions)` | 优雅地忽略指定类型的异常，简化 try-except-pass 代码块                                    |

> [!tip]
>
> 想要在资源管理时提供清晰的“前置准备”与“后置清理”逻辑，`@contextmanager` 是最简洁、最具 Python 范（Pythonic）的编写方式。

```python
from contextlib import contextmanager

@contextmanager
def database_transaction():
    print("[开始事务] 连接数据库...")
    try:
        yield  # 业务代码在此处执行
    except Exception as e:
        print(f"[事务回滚] 捕获到异常: {e}")
        raise
    else:
        print("[事务提交] 数据成功写入！")
    finally:
        print("[清理资源] 释放数据库连接。")

# 使用自定义上下文管理器
with database_transaction():
    print("正在执行核心数据入库操作...")
```

## 十五、其他中低频内置模块及第三方替代方案对照

在实际应用中，部分内置模块因为 API 设计较为陈旧、性能有限或过于底层，在现代 Python 生态中往往会被更成熟、更易用的**第三方库**所替代。

下表总结了这些中低频内置模块的特性、局限性以及主流的工业级第三方替代方案，供你在日常开发中进行技术选型：

| 内置模块       | 简单介绍 / 典型底层场景                                           | 局限性 / 不足                                                                              | 工业级首选第三方替代方案                        | 替代理由与说明                                                                                                                       |
| :------------- | :---------------------------------------------------------------- | :----------------------------------------------------------------------------------------- | :---------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------- |
| **`unittest`** | 内置单元测试框架。基于类和继承的传统测试结构。                    | 语法偏向 Java 风格（大量 `self.assertXXX`），编写繁琐，不够 Pythonic。                     | **`pytest`**                                    | 目前 Python 测试领域的事实标准。支持纯函数测试和直接使用 Python 自带的 `assert` 断言，插件极其丰富，完全兼容 `unittest` 编写的用例。 |
| **`argparse`** | 内置命令行 (CLI) 参数解析器。                                     | 语法稍微冗长，处理复杂的嵌套子命令 and 自动补全比较繁杂。                                  | **`typer`** 或 **`click`**                      | `typer` 能够基于类型提示（Type Hints）零配置地生成美观、易用的命令行界面，开发体验极佳。                                             |
