### A.1 连接管理

### A.3 表操作

| 命令 | 说明 |
|------|------|
| `SHOW TABLES;` | 列出当前库的所有表 |
| `SHOW TABLES FROM db_name;` | 列出指定库的表 |
| `DESC table_name;` 或 `DESCRIBE table_name;` | 查看表结构（字段名、类型、默认值等） |
| `SHOW CREATE TABLE table_name;` | 查看表的完整创建语句 |
| `SHOW COLUMNS FROM table_name;` | 查看列信息（同 DESC） |
| `SHOW INDEX FROM table_name;` | 查看表的索引信息 |
| `SHOW TABLE STATUS;` | 查看所有表的状态信息 |
| `SHOW TABLE STATUS LIKE 'user%';` | 模糊匹配表名查看状态 |

```sql
-- 创建表的标准写法
CREATE TABLE users (
  id          BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  username    VARCHAR(64)  NOT NULL                COMMENT '用户名',
  email       VARCHAR(255) NOT NULL                COMMENT '邮箱',
  age         INT          DEFAULT NULL             COMMENT '年龄',
  status      TINYINT      NOT NULL DEFAULT 1       COMMENT '状态: 0-禁用 1-启用',
  balance     DECIMAL(12,2) NOT NULL DEFAULT 0.00  COMMENT '余额',
  created_at  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  updated_at  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (id),
  UNIQUE KEY uk_username (username),
  UNIQUE KEY uk_email (email),
  KEY idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户表';

-- 添加列
ALTER TABLE users ADD COLUMN phone VARCHAR(20) DEFAULT NULL COMMENT '手机号' AFTER email;

-- 修改列类型
ALTER TABLE users MODIFY COLUMN age TINYINT UNSIGNED DEFAULT NULL COMMENT '年龄';

-- 重命名列
ALTER TABLE users CHANGE COLUMN username user_name VARCHAR(64) NOT NULL COMMENT '用户名';

-- 删除列
ALTER TABLE users DROP COLUMN age;

-- 重命名表
ALTER TABLE users RENAME TO sys_users;
-- 或
RENAME TABLE users TO sys_users;

-- 删除表
DROP TABLE IF EXISTS users;

-- 清空表（保留结构，重置自增）
TRUNCATE TABLE users;

-- 添加主键
ALTER TABLE users ADD PRIMARY KEY (id);

-- 添加外键
ALTER TABLE orders ADD CONSTRAINT fk_orders_user
  FOREIGN KEY (user_id) REFERENCES users(id)
  ON DELETE RESTRICT ON UPDATE CASCADE;

-- 删除外键
ALTER TABLE orders DROP FOREIGN KEY fk_orders_user;
```

### A.4 数据增删改

```sql
-- INSERT 单行插入
INSERT INTO users (username, email, age)
VALUES ('alice', 'alice@example.com', 25);

-- INSERT 多行插入
INSERT INTO users (username, email, age)
VALUES
  ('bob',   'bob@example.com',   30),
  ('carol', 'carol@example.com', 28),
  ('dave',  'dave@example.com',  35);

-- INSERT ... SET 语法
INSERT INTO users SET username='eve', email='eve@example.com', age=22;

-- INSERT ... ON DUPLICATE KEY UPDATE（UPSERT）
INSERT INTO users (id, username, email)
VALUES (1, 'alice', 'alice_new@example.com')
ON DUPLICATE KEY UPDATE email = VALUES(email), updated_at = NOW();

-- INSERT ... SELECT
INSERT INTO users_archive (username, email, created_at)
SELECT username, email, created_at FROM users WHERE status = 0;

-- REPLACE INTO（先删后插，会改变自增ID，谨慎使用）
REPLACE INTO users (id, username, email)
VALUES (1, 'alice', 'alice_updated@example.com');

-- UPDATE 基本语法
UPDATE users SET age = 26, updated_at = NOW() WHERE id = 1;

-- UPDATE 多表关联更新
UPDATE orders o
  JOIN users u ON o.user_id = u.id
SET o.amount = o.amount * 0.9
WHERE u.status = 1 AND o.status = 'paid';

-- UPDATE 使用 CASE
UPDATE users SET status = CASE
  WHEN age < 18 THEN 0
  WHEN age >= 18 THEN 1
END;

-- DELETE 基本语法
DELETE FROM users WHERE id = 100;

-- DELETE 多表关联删除
DELETE u, o FROM users u
  JOIN orders o ON o.user_id = u.id
WHERE u.id = 100;

-- DELETE 使用子查询
DELETE FROM users WHERE id IN (
  SELECT user_id FROM user_blacklist WHERE expire_at < NOW()
);

-- TRUNCATE（清空整表，比 DELETE 快，不可回滚）
TRUNCATE TABLE temp_users;

-- TRUNCATE 与 DELETE 的区别:
-- DELETE: 可以加 WHERE, 逐行删除, 可以回滚, 不重置 AUTO_INCREMENT
-- TRUNCATE: 整表清空, 不可回滚, 重置 AUTO_INCREMENT, 更快
```

### A.5 查询

```sql
-- 基本查询
SELECT id, username, email FROM users;

-- 全部列
SELECT * FROM users;

-- 去重
SELECT DISTINCT status FROM users;

-- WHERE 条件
SELECT * FROM users WHERE age >= 18 AND status = 1;
SELECT * FROM users WHERE age BETWEEN 18 AND 60;
SELECT * FROM users WHERE username IN ('alice', 'bob', 'carol');
SELECT * FROM users WHERE username LIKE 'al%';
SELECT * FROM users WHERE email IS NOT NULL;
SELECT * FROM users WHERE age > 20 AND (status = 1 OR age > 50);

-- ORDER BY 排序
SELECT * FROM users ORDER BY created_at DESC;
SELECT * FROM users ORDER BY status ASC, created_at DESC;

-- GROUP BY 分组
SELECT status, COUNT(*) AS total FROM users GROUP BY status;

-- 多列分组
SELECT status, age, COUNT(*) AS total
FROM users
GROUP BY status, age;

-- HAVING 过滤分组（WHERE 在分组前过滤，HAVING 在分组后过滤）
SELECT status, COUNT(*) AS total
FROM users
GROUP BY status
HAVING COUNT(*) > 10;

-- HAVING 使用聚合结果
SELECT user_id, SUM(amount) AS total_amount
FROM orders
GROUP BY user_id
HAVING SUM(amount) > 10000;

-- LIMIT 分页
SELECT * FROM users LIMIT 10;           -- 前 10 条
SELECT * FROM users LIMIT 20, 10;       -- 跳过 20 条取 10 条（偏移量写法）
SELECT * FROM users LIMIT 10 OFFSET 20; -- 跳过 20 条取 10 条（OFFSET 写法）

-- 聚合函数
SELECT
  COUNT(*)         AS total_users,
  COUNT(email)     AS users_with_email,
  AVG(age)         AS avg_age,
  MIN(age)         AS min_age,
  MAX(age)         AS max_age,
  SUM(balance)     AS total_balance
FROM users;

-- 窗口函数（MySQL 8.0+）
-- 按状态分组，给每行编号
SELECT
  username,
  status,
  age,
  ROW_NUMBER() OVER (PARTITION BY status ORDER BY age DESC) AS rn,
  RANK()       OVER (PARTITION BY status ORDER BY age DESC) AS rank_val,
  DENSE_RANK() OVER (PARTITION BY status ORDER BY age DESC) AS dense_rank_val
FROM users;

-- CTE 公用表表达式（MySQL 8.0+）
WITH active_users AS (
  SELECT id, username FROM users WHERE status = 1
)
SELECT u.username, COUNT(o.id) AS order_count
FROM active_users u
LEFT JOIN orders o ON o.user_id = u.id
GROUP BY u.id, u.username;

-- WITH RECURSIVE 递归查询
WITH RECURSIVE numbers AS (
  SELECT 1 AS n
  UNION ALL
  SELECT n + 1 FROM numbers WHERE n < 10
)
SELECT * FROM numbers;

-- CASE 表达式
SELECT
  username,
  CASE
    WHEN age < 18 THEN 'minor'
    WHEN age < 60 THEN 'adult'
    ELSE 'senior'
  END AS age_group
FROM users;
```

### A.6 JOIN

```sql
-- INNER JOIN 内连接（只返回两表匹配的行）
SELECT u.username, o.order_id, o.amount
FROM users u
INNER JOIN orders o ON u.id = o.user_id;

-- LEFT JOIN 左连接（左表全保留，右表不匹配的为 NULL）
SELECT u.username, o.order_id
FROM users u
LEFT JOIN orders o ON u.id = o.user_id;

-- LEFT JOIN 找不匹配的行（常用于查"没有订单的用户"）
SELECT u.username
FROM users u
LEFT JOIN orders o ON u.id = o.user_id
WHERE o.id IS NULL;

-- RIGHT JOIN 右连接（右表全保留）
SELECT u.username, o.order_id
FROM users u
RIGHT JOIN orders o ON u.id = o.user_id;

-- 多表 JOIN
SELECT u.username, o.order_id, p.product_name, oi.quantity
FROM users u
JOIN orders o       ON u.id = o.user_id
JOIN order_items oi ON o.id = oi.order_id
JOIN products p     ON oi.product_id = p.id;

-- 自连接（如查同一表中上下级关系）
SELECT e.name AS employee, m.name AS manager
FROM employees e
LEFT JOIN employees m ON e.manager_id = m.id;

-- CROSS JOIN 交叉连接（笛卡尔积）
SELECT c.category_name, s.size_name
FROM categories c
CROSS JOIN sizes s;

-- USING 语法（当两表连接列同名时）
SELECT u.username, o.order_id
FROM users u
JOIN orders o USING (user_id);
```

```sql
CREATE FULLTEXT INDEX ft_content ON articles(content);
```

### A.8 事务

```sql
-- 开启事务
BEGIN;
-- 或
START TRANSACTION;

-- 提交事务
COMMIT;

-- 回滚事务
ROLLBACK;

-- 设置保存点
BEGIN;
INSERT INTO orders (user_id, amount) VALUES (1, 100);
SAVEPOINT sp1;
INSERT INTO orders (user_id, amount) VALUES (2, 200);
-- 回滚到保存点
ROLLBACK TO SAVEPOINT sp1;
-- 此时会保留 user_id=1 的插入，撤销 user_id=2 的插入
COMMIT;

-- 删除保存点
RELEASE SAVEPOINT sp1;

-- 设置隔离级别（事务级别，影响当前会话）
SET TRANSACTION ISOLATION LEVEL READ UNCOMMITTED;
SET TRANSACTION ISOLATION LEVEL READ COMMITTED;
SET TRANSACTION ISOLATION LEVEL REPEATABLE READ;  -- MySQL 默认
SET TRANSACTION ISOLATION LEVEL SERIALIZABLE;

-- 设置全局隔离级别
SET GLOBAL transaction_isolation = 'READ-COMMITTED';

-- 查看当前隔离级别
SELECT @@transaction_isolation;

-- 查看锁信息
SELECT * FROM information_schema.INNODB_TRX;          -- 当前事务
SELECT * FROM performance_schema.data_locks;         -- 当前锁（MySQL 8.0+）
SELECT * FROM performance_schema.data_lock_waits;     -- 锁等待（MySQL 8.0+）

-- 死锁检测
SHOW ENGINE INNODB STATUS\G
```

### A.11 JSON 操作

```sql
-- 创建含 JSON 列的表
CREATE TABLE products (
  id    BIGINT AUTO_INCREMENT PRIMARY KEY,
  name  VARCHAR(100),
  attrs JSON
);

-- 插入 JSON 数据
INSERT INTO products (name, attrs) VALUES
  ('Laptop', '{"color": "silver", "specs": {"cpu": "i7", "ram": 16}, "tags": ["tech", "portable"]}'),
  ('Phone',  '{"color": "black",  "specs": {"cpu": "A15", "ram": 8}, "tags": ["mobile", "5g"]}');

-- JSON_EXTRACT 提取值（返回 JSON 类型）
SELECT JSON_EXTRACT(attrs, '$.color') AS color FROM products;

-- -> 操作符（等价 JSON_EXTRACT，返回 JSON 类型）
SELECT attrs->'$.color' AS color FROM products;

-- ->> 操作符（返回纯文本，去掉引号）
SELECT attrs->>'$.color' AS color FROM products;

-- 提取嵌套属性
SELECT attrs->'$.specs.cpu' AS cpu FROM products;

-- 提取数组元素
SELECT attrs->'$.tags[0]' AS first_tag FROM products;

-- JSON_OBJECT 创建 JSON 对象
SELECT JSON_OBJECT('name', 'Alice', 'age', 25, 'active', TRUE) AS json_obj;

-- JSON_ARRAY 创建 JSON 数组
SELECT JSON_ARRAY('apple', 'banana', 'cherry') AS json_arr;

-- JSON_SET 修改或添加属性
UPDATE products
SET attrs = JSON_SET(attrs, '$.color', 'gold', '$.weight', 1.5)
WHERE id = 1;

-- JSON_INSERT 仅添加不存在的属性
UPDATE products SET attrs = JSON_INSERT(attrs, '$.brand', 'Acme') WHERE id = 1;

-- JSON_REPLACE 仅替换已存在的属性
UPDATE products SET attrs = JSON_REPLACE(attrs, '$.color', 'blue') WHERE id = 1;

-- JSON_REMOVE 删除属性
UPDATE products SET attrs = JSON_REMOVE(attrs, '$.weight') WHERE id = 1;

-- JSON_CONTAINS 检查是否包含
SELECT * FROM products WHERE JSON_CONTAINS(attrs->'$.tags', '"mobile"');

-- JSON_CONTAINS_PATH 检查路径是否存在
SELECT * FROM products WHERE JSON_CONTAINS_PATH(attrs, 'one', '$.color', '$.weight');

-- JSON_LENGTH 获取数组或对象长度
SELECT JSON_LENGTH(attrs->'$.tags') AS tag_count FROM products;

-- JSON_KEYS 获取所有键
SELECT JSON_KEYS(attrs) AS keys FROM products;

-- JSON_TABLE 将 JSON 转为关系表（MySQL 8.0+）
SELECT * FROM products,
  JSON_TABLE(attrs, '$.tags[*]' COLUMNS (tag VARCHAR(50) PATH '$')) AS jt;
```

### A.12 实用函数

#### 日期时间函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `NOW()` | 当前日期时间 | `SELECT NOW();` |
| `CURDATE()` | 当前日期 | `SELECT CURDATE();` |
| `CURTIME()` | 当前时间 | `SELECT CURTIME();` |
| `UNIX_TIMESTAMP()` | 转 Unix 时间戳 | `SELECT UNIX_TIMESTAMP(NOW());` |

```sql
VALUES (1, 'alice', 'alice_new@example.com')
ON CONFLICT (id)
DO UPDATE SET email = EXCLUDED.email, updated_at = now()
RETURNING id, (xmax = 0) AS inserted;  -- inserted=true 表示是新增

-- UPSERT：ON CONFLICT 不做任何操作
INSERT INTO users (id, username, email)
VALUES (1, 'alice', 'alice@example.com')
ON CONFLICT (id) DO NOTHING;

UPDATE users SET status = 0 WHERE age < 18

WHERE o.user_id = u.id AND u.status = 1;

  WHEN age < 18 THEN 0
```

### B.5 查询

```sql
-- 基本查询
SELECT id, username, email FROM users;

-- 去重
SELECT DISTINCT status FROM users;

-- WHERE 条件（PostgreSQL 支持 ILIKE 不区分大小写）
SELECT * FROM users WHERE age >= 18 AND status = 1;
SELECT * FROM users WHERE age BETWEEN 18 AND 60;
SELECT * FROM users WHERE username IN ('alice', 'bob');
SELECT * FROM users WHERE username LIKE 'al%';
SELECT * FROM users WHERE username ILIKE 'AL%';       -- 不区分大小写
SELECT * FROM users WHERE email IS NOT NULL;

-- ORDER BY
SELECT * FROM users ORDER BY created_at DESC;
SELECT * FROM users ORDER BY status ASC NULLS LAST;     -- NULL 排在最后

-- GROUP BY
SELECT status, COUNT(*) AS total FROM users GROUP BY status;

-- HAVING
SELECT status, COUNT(*) AS total
FROM users
GROUP BY status
HAVING COUNT(*) > 10;

-- LIMIT / OFFSET 分页
SELECT * FROM users LIMIT 10;
SELECT * FROM users LIMIT 10 OFFSET 20;

-- FETCH FIRST 语法（SQL 标准，等价 LIMIT）
SELECT * FROM users
ORDER BY created_at DESC
OFFSET 20 ROWS
FETCH FIRST 10 ROWS ONLY;

-- 聚合函数
SELECT
  COUNT(*)         AS total_users,
  COUNT(email)     AS users_with_email,
  AVG(age)         AS avg_age,
  MIN(age)         AS min_age,
  MAX(age)         AS max_age,
  SUM(balance)     AS total_balance,
  -- PostgreSQL 特色：string_agg 等价 MySQL GROUP_CONCAT
  STRING_AGG(username, ', ' ORDER BY username) AS user_list,
  -- 聚合为 JSON 数组
  JSONB_AGG(username) AS user_json
FROM users;

-- 窗口函数
SELECT
  username,
  status,
  age,
  ROW_NUMBER() OVER (PARTITION BY status ORDER BY age DESC) AS rn,
  RANK()       OVER (PARTITION BY status ORDER BY age DESC) AS rank_val,
  DENSE_RANK() OVER (PARTITION BY status ORDER BY age DESC) AS dense_rank_val,
  -- PostgreSQL 独有窗口函数
  LAG(age)     OVER (PARTITION BY status ORDER BY age)  AS prev_age,
  LEAD(age)    OVER (PARTITION BY status ORDER BY age)  AS next_age,
  FIRST_VALUE(username) OVER (PARTITION BY status ORDER BY age) AS first_user,
  NTILE(4)     OVER (ORDER BY age) AS quartile
FROM users;

-- CTE
WITH active_users AS (
  SELECT id, username FROM users WHERE status = 1
)
SELECT u.username, COUNT(o.id) AS order_count
FROM active_users u
LEFT JOIN orders o ON o.user_id = u.id
GROUP BY u.id, u.username;

-- WITH RECURSIVE 递归
WITH RECURSIVE numbers AS (
  SELECT 1 AS n
  UNION ALL
  SELECT n + 1 FROM numbers WHERE n < 10
)
SELECT * FROM numbers;

-- 递归查询组织架构树
WITH RECURSIVE org_tree AS (
  -- 锚点：顶级节点
  SELECT id, name, parent_id, 0 AS level, name::TEXT AS path
  FROM departments WHERE parent_id IS NULL

  UNION ALL

  -- 递归：子节点
  SELECT d.id, d.name, d.parent_id, ot.level + 1,
    ot.path || ' -> ' || d.name
  FROM departments d
  JOIN org_tree ot ON d.parent_id = ot.id
)
SELECT * FROM org_tree ORDER BY path;

-- FILTER 子句（PostgreSQL 特色，替代 CASE WHEN 聚合）
SELECT
  COUNT(*)                          AS total,
  COUNT(*) FILTER (WHERE age >= 18) AS adults,
  COUNT(*) FILTER (WHERE age < 18)  AS minors,
  AVG(age) FILTER (WHERE status = 1) AS avg_active_age
FROM users;

-- DISTINCT ON（PostgreSQL 特色，每组取第一条）
-- 查询每个用户最新的一条订单
SELECT DISTINCT ON (user_id)
  user_id, order_id, created_at
FROM orders
ORDER BY user_id, created_at DESC;

-- VALUES 子句作为临时表
SELECT * FROM (VALUES
  (1, 'alice'),
  (2, 'bob'),
  (3, 'carol')
) AS t(id, name);

-- LATERAL 子查询（PostgreSQL 特色）
-- 每个用户取最新的 3 条订单
SELECT u.username, o.order_id, o.created_at
FROM users u,
  LATERAL (
    SELECT order_id, created_at
    FROM orders
    WHERE user_id = u.id
    ORDER BY created_at DESC
    LIMIT 3
  ) o;
```

### B.11 JSONB 操作

```sql
-- 创建含 JSONB 列的表
CREATE TABLE products (
  id    BIGSERIAL PRIMARY KEY,
  name  VARCHAR(100),
  attrs JSONB
);

-- 插入 JSON 数据
INSERT INTO products (name, attrs) VALUES
  ('Laptop', '{"color": "silver", "specs": {"cpu": "i7", "ram": 16}, "tags": ["tech", "portable"], "price": 9999}'),
  ('Phone',  '{"color": "black",  "specs": {"cpu": "A15", "ram": 8}, "tags": ["mobile", "5g"], "price": 5999}');

-- -> 提取 JSON 对象/数组（返回 JSONB 类型）
SELECT attrs->'color' AS color FROM products;

-- ->> 提取为文本（返回 TEXT 类型）
SELECT attrs->>'color' AS color FROM products;

-- 提取嵌套属性
SELECT attrs->'specs'->>'cpu' AS cpu FROM products;

-- 提取数组元素
SELECT attrs->'tags'->0 AS first_tag FROM products;

-- @> 包含操作符（检查 JSONB 是否包含指定的键值/元素）
-- 检查 color 是否为 silver
SELECT * FROM products WHERE attrs @> '{"color": "silver"}';
-- 检查 tags 数组是否包含 "mobile"
SELECT * FROM products WHERE attrs @> '{"tags": ["mobile"]}';
-- 检查嵌套属性
SELECT * FROM products WHERE attrs @> '{"specs": {"cpu": "i7"}}';

-- ? 键存在检查（检查顶层键是否存在）
SELECT * FROM products WHERE attrs ? 'color';

-- ?| 键存在检查（任一存在）
SELECT * FROM products WHERE attrs ?| array['color', 'weight'];

-- ?& 键存在检查（全部存在）
SELECT * FROM products WHERE attrs ?& array['color', 'weight'];

-- jsonb_set 修改/添加值
-- 路径用数组表示: '{specs,cpu}'
UPDATE products
SET attrs = jsonb_set(attrs, '{specs,cpu}', '"i9"')
WHERE id = 1;

-- jsonb_set 如果键不存在则创建
UPDATE products
SET attrs = jsonb_set(attrs, '{weight}', '1.5', true)  -- true=不存在时创建
WHERE id = 1;

-- || 合并操作符（后者覆盖前者同名键）
UPDATE products SET attrs = attrs || '{"color": "gold", "brand": "Acme"}' WHERE id = 1;

-- 删除键
UPDATE products SET attrs = attrs - 'weight' WHERE id = 1;
-- 删除嵌套键
UPDATE products SET attrs = attrs #- '{specs,cpu}' WHERE id = 1;

-- jsonb_build_object 构建对象
SELECT jsonb_build_object('name', name, 'price', attrs->>'price') FROM products;

-- jsonb_agg 聚合为 JSON 数组
SELECT
  status,
  jsonb_agg(jsonb_build_object('id', id, 'username', username)) AS users
FROM users
GROUP BY status;

-- jsonb_object_agg 聚合为 JSON 对象
SELECT
  jsonb_object_agg(username, email) AS user_emails
FROM users;

-- jsonb_each 展开为键值对行
SELECT key, value FROM products, jsonb_each(attrs);

-- jsonb_array_elements 展开数组
SELECT id, tag
FROM products,
  jsonb_array_elements_text(attrs->'tags') AS tag;

-- jsonb_typeof 获取类型
SELECT jsonb_typeof(attrs->'color') FROM products;

-- GIN 索引（JSONB 查询性能优化）
CREATE INDEX idx_products_attrs ON products USING GIN (attrs);

-- jsonb_path_query（JSONPath 查询，PostgreSQL 12+）
SELECT jsonb_path_query(attrs, '$.specs.cpu') FROM products;

-- jsonb_path_exists（检查路径是否存在）
SELECT * FROM products
WHERE jsonb_path_exists(attrs, '$.tags[*] ? (@ == "mobile")');
```

```sql
  status,

FROM users

SELECT array_remove(ARRAY[1,2,3], 2);       -- {1,3}

SELECT array_to_string(ARRAY['a','b','c'], ', ');  -- a, b, c
```

### B.13 特色语法

```sql
-- RETURNING 子句（INSERT/UPDATE/DELETE 均支持）
INSERT INTO users (username, email) VALUES ('frank', 'f@e.com')
  RETURNING id, username, created_at;

UPDATE users SET status = 0 WHERE age < 18
  RETURNING id, username;

DELETE FROM users WHERE status = 0
  RETURNING id, username;

-- CTE / WITH RECURSIVE 递归
-- 树形结构遍历
CREATE TABLE departments (
  id SERIAL PRIMARY KEY,
  name VARCHAR(50),
  parent_id INT REFERENCES departments(id)
);

-- 查询某部门的所有子部门
WITH RECURSIVE sub_tree AS (
  SELECT id, name, parent_id, 0 AS depth
  FROM departments WHERE id = 1

  UNION ALL

  SELECT d.id, d.name, d.parent_id, st.depth + 1
  FROM departments d
  JOIN sub_tree st ON d.parent_id = st.id
)
SELECT * FROM sub_tree;

-- MATERIALIZED 物化 CTE（只计算一次，多次引用时提高性能）
WITH expensive_calc AS MATERIALIZED (
  SELECT user_id, SUM(amount) AS total FROM orders GROUP BY user_id
)
SELECT u.username, ec.total
FROM users u
JOIN expensive_calc ec ON u.id = ec.user_id
UNION ALL
SELECT 'TOTAL', SUM(total) FROM expensive_calc;

-- 物化视图
CREATE MATERIALIZED VIEW user_order_stats AS
SELECT
  u.id,
  u.username,
  COUNT(o.id)   AS order_count,
  SUM(o.amount)  AS total_amount
FROM users u
LEFT JOIN orders o ON o.user_id = u.id
GROUP BY u.id, u.username;

-- 刷新物化视图
REFRESH MATERIALIZED VIEW user_order_stats;

-- 并发刷新（不阻塞查询，需要唯一索引）
CREATE UNIQUE INDEX idx_mvs_id ON user_order_stats(id);
REFRESH MATERIALIZED VIEW CONCURRENTLY user_order_stats;

-- 序列操作
-- 创建序列
CREATE SEQUENCE orders_seq START 100;

-- 获取下一个值
SELECT nextval('orders_seq');

-- 获取当前值（不递增）
SELECT currval('orders_seq');

-- 设置序列值
SELECT setval('orders_seq', 500);

-- 查看序列信息
SELECT * FROM orders_seq;

-- 重置序列
ALTER SEQUENCE orders_id_seq RESTART WITH 1;

-- EXCLUDE 约束（防止时间范围重叠，PostgreSQL 特色）
-- 如会议室预订不能时间重叠
CREATE TABLE room_bookings (
  id SERIAL PRIMARY KEY,
  room_id INT,
  during TSRANGE,
  EXCLUDE USING GiST (room_id WITH =, during WITH &&)
);

-- FILTER 子句（更简洁的条件聚合）
SELECT
  COUNT(*)                          AS total,
  COUNT(*) FILTER (WHERE status = 1) AS active,
  COUNT(*) FILTER (WHERE status = 0) AS inactive,
  SUM(amount) FILTER (WHERE status = 1) AS active_total
FROM orders;

-- DISTINCT ON（每组取一条）
SELECT DISTINCT ON (user_id)
  user_id, order_id, created_at
FROM orders
ORDER BY user_id, created_at DESC;

-- 范围类型
SELECT '[2024-01-01, 2024-12-31]'::daterange;
SELECT '[1, 10]'::int4range;
-- 检查范围重叠
SELECT '[1,5]'::int4range && '[3,8]'::int4range;  -- true

-- ENUM 类型
CREATE TYPE order_status AS ENUM ('pending', 'paid', 'shipped', 'delivered', 'cancelled');
CREATE TABLE orders (id BIGSERIAL, status order_status NOT NULL DEFAULT 'pending');
```

### C.1 数据类型映射对照

| 场景 | MySQL 类型 | PostgreSQL 类型 | 说明 |

| 无符号整数 | `INT UNSIGNED` | `INTEGER` | PG 不支持 UNSIGNED |
| 浮点数 | `FLOAT` / `DOUBLE` | `REAL` / `DOUBLE PRECISION` | 名称不同 |

### C.7 自增/序列差异

| 功能 | MySQL | PostgreSQL |
|------|-------|-------------|
| 自增列 | `AUTO_INCREMENT` | `SERIAL` / `BIGSERIAL` / `GENERATED ALWAYS AS IDENTITY` |
| 查看自增值 | `SELECT LAST_INSERT_ID();` | `SELECT currval('table_id_seq');` |
| 设置自增值 | `ALTER TABLE t AUTO_INCREMENT = 100;` | `SELECT setval('table_id_seq', 100);` |

### C.8 UPSERT 语法差异

| 功能 | MySQL | PostgreSQL |
|------|-------|-------------|
| 存在则更新 | `INSERT ... ON DUPLICATE KEY UPDATE col = VALUES(col)` | `INSERT ... ON CONFLICT (col) DO UPDATE SET col = EXCLUDED.col` |
| 存在则忽略 | `INSERT IGNORE INTO ...` | `INSERT ... ON CONFLICT (col) DO NOTHING` |
| 返回操作类型 | 无 | `RETURNING id, (xmax = 0) AS inserted` |

```sql
-- MySQL UPSERT
INSERT INTO users (id, username, email)
VALUES (1, 'alice', 'alice_new@example.com')
ON DUPLICATE KEY UPDATE email = VALUES(email), updated_at = NOW();

-- PostgreSQL UPSERT
INSERT INTO users (id, username, email)
VALUES (1, 'alice', 'alice_new@example.com')
ON CONFLICT (id) DO UPDATE
SET email = EXCLUDED.email, updated_at = now()
RETURNING id, (xmax = 0) AS is_inserted;
```

### C.9 类型转换差异

| 功能 | MySQL | PostgreSQL |
|------|-------|-------------|
| CAST | `CAST(expr AS SIGNED)` | `CAST(expr AS INTEGER)` |
| CONVERT | `CONVERT(expr, SIGNED)` | 不支持此语法 |
| 字符串转整数 | `CAST('123' AS SIGNED)` | `'123'::INTEGER` |
| 字符串转日期 | `STR_TO_DATE(s, fmt)` | `s::DATE` 或 `to_date(s, fmt)` |
| 整数转字符串 | `CAST(100 AS CHAR)` | `100::TEXT` |
| 隐式转换 | 较宽松（自动转换字符串数字） | 严格（必须显式转换） |
| :: 语法 | 不支持 | `expr::type`（PG 特色简写） |

```sql
-- MySQL: 隐式转换（可以工作但不推荐）
SELECT * FROM users WHERE id = '1';      -- 字符串 '1' 自动转为整数 1

-- PostgreSQL: 严格类型（会报错）
SELECT * FROM users WHERE id = '1';       -- ERROR: operator does not exist: bigint = text
SELECT * FROM users WHERE id = '1'::BIGINT;  -- 正确
SELECT * FROM users WHERE id = 1;            -- 正确
```

### C.10 布尔类型差异

| 功能 | MySQL | PostgreSQL |
|------|-------|-------------|
| 布尔类型 | `TINYINT(1)` (0/1) | `BOOLEAN` (true/false) |
| 真值 | `1` | `TRUE` 或 `true` |
| 假值 | `0` | `FALSE` 或 `false` |
| 布尔表达式 | `status = 1` | `status = TRUE` 或 `is_active` |
| 布尔聚合 | 无 | `BOOL_AND(expr)` / `BOOL_OR(expr)` |
| WHERE 用布尔列 | `WHERE is_active = 1` | `WHERE is_active` 或 `WHERE is_active = TRUE` |

## 附录 D：数据库表设计检查清单（Checklist）

> 每次新建表或修改表结构时，逐项检查。全部打勾后再提交。

### D.1 命名规范检查项

- [ ] 表名使用小写蛇形命名（snake_case），如 `user_orders`，不用驼峰
- [ ] 表名使用复数形式，如 `users`、`orders`，统一风格
- [ ] 列名使用小写蛇形命名，如 `created_at`、`user_id`
- [ ] 主键列统一命名为 `id`（单表内）
- [ ] 外键列命名为 `{引用表单数}_id`，如 `user_id`、`order_id`
- [ ] 布尔列以 `is_` 或 `has_` 开头，如 `is_active`、`has_paid`
- [ ] 日期时间列以 `_at` 结尾，如 `created_at`、`updated_at`、`deleted_at`
- [ ] 金额列以 `_amount` 或 `_price` 结尾，如 `total_amount`、`unit_price`
- [ ] 索引名以 `idx_` 开头，唯一索引以 `uk_` 或 `uq_` 开头
- [ ] 外键约束以 `fk_` 开头，如 `fk_orders_user`
- [ ] 检查约束以 `chk_` 开头，如 `chk_age_range`
- [ ] 避免使用数据库保留字作为表名或列名（如 `order`、`user`、`group`）

### D.2 主键设计检查项

- [ ] 每张表都有主键
- [ ] 主键选择 BIGINT 类型（不用 INT，避免溢出）
- [ ] 主键使用自增序列（MySQL: AUTO_INCREMENT / PostgreSQL: BIGSERIAL）
- [ ] 不使用 UUID 作为聚簇索引主键（插入性能差），如需 UUID 用额外列
- [ ] 不使用复合主键（除非是关联表的联合主键）
- [ ] 主键值不可修改、不可复用
- [ ] 不使用业务字段作为主键（如手机号、身份证号）

### D.3 字段类型检查项

- [ ] 金额字段使用 DECIMAL(12,2) 或 NUMERIC(12,2)，不用 FLOAT/DOUBLE
- [ ] 字符串字段使用 VARCHAR 并指定合理长度，不用 TEXT（除非确实需要长文本）
- [ ] 布尔字段使用 BOOLEAN（PostgreSQL）或 TINYINT(1)（MySQL）
- [ ] 时间字段使用 TIMESTAMP 或 DATETIME，不用 VARCHAR 存日期
- [ ] 枚举字段使用 SMALLINT + 应用层映射，或数据库 ENUM 类型
- [ ] IP 地址使用 VARCHAR(45)（兼容 IPv6），不用 INT
- [ ] JSON 字段使用 JSONB（PostgreSQL）或 JSON（MySQL 8.0+）
- [ ] 外键字段类型与引用表主键类型完全一致
- [ ] 不使用 SELECT *，明确列出所有列
- [ ] 每个字段都有合理的 NOT NULL 或 DEFAULT 约束
- [ ] 能用 SMALLINT 的不用 INT，能用 INT 的不用 BIGINT

### D.4 索引设计检查项

- [ ] WHERE 条件中频繁使用的列建索引
- [ ] JOIN 关联字段建索引（外键列）
- [ ] ORDER BY / GROUP BY 涉及的列建索引
- [ ] 联合索引遵循最左前缀原则，将区分度高的列放前面
- [ ] 唯一约束的字段建唯一索引
- [ ] 避免在低区分度列上单独建索引（如 status 只有 0/1）
- [ ] 避免索引过多（单表索引不超过 5-7 个）
- [ ] 长字符串使用前缀索引（MySQL）或部分索引（PostgreSQL）
- [ ] 不在频繁更新的列上建过多索引（影响写入性能）
- [ ] JSONB 列考虑建 GIN 索引（PostgreSQL）
- [ ] 查询前用 EXPLAIN 验证索引是否生效
- [ ] 删除不再使用的索引（定期审计）

### D.5 约束设计检查项

- [ ] 非空约束：业务必填字段加 NOT NULL
- [ ] 唯一约束：业务唯一标识加 UNIQUE（如 username、email）
- [ ] 检查约束：值范围有限制的加 CHECK（如 age >= 0、amount >= 0）
- [ ] 默认值：有合理默认值的加 DEFAULT（如 status DEFAULT 1）
- [ ] 外键约束：关联关系明确的外键加 FK 约束
- [ ] 外键删除策略：明确 ON DELETE 行为（RESTRICT / CASCADE / SET NULL）
- [ ] 外键更新策略：明确 ON UPDATE 行为
- [ ] 枚举值检查：状态字段加 CHECK 约束限定取值范围

### D.6 审计字段检查项

- [ ] 每张业务表都有 `created_at`（创建时间），DEFAULT CURRENT_TIMESTAMP
- [ ] 每张业务表都有 `updated_at`（更新时间），ON UPDATE CURRENT_TIMESTAMP（MySQL）或触发器（PostgreSQL）
- [ ] 每张业务表都有 `created_by`（创建人 ID），记录操作来源
- [ ] 每张业务表都有 `updated_by`（更新人 ID）
- [ ] 软删除场景加 `deleted_at` 字段，删除时设置时间戳
- [ ] 软删除场景加 `is_deleted` 字段或通过 `deleted_at IS NOT NULL` 判断
- [ ] 关键业务表加 `version` 乐观锁字段

### D.7 安全设计检查项

- [ ] 密码字段存储为哈希值（bcrypt / argon2），不存明文
- [ ] 敏感信息（身份证号、手机号）加密存储或脱敏
- [ ] 数据库连接使用 SSL/TLS 加密
- [ ] 应用使用最小权限账号连接数据库（不用 root/superuser）
- [ ] SQL 查询全部使用参数化查询（防 SQL 注入）
- [ ] 不在代码中硬编码数据库密码（使用环境变量或密钥管理）
- [ ] 数据库备份文件加密存储
- [ ] 敏感操作（删除/修改）记录审计日志
- [ ] 限制数据库远程访问 IP 白名单

### D.8 性能设计检查项

- [ ] 大表查询都有索引覆盖（避免全表扫描）
- [ ] 避免 SELECT *，只查需要的列
- [ ] 分页查询大数据集使用游标分页（keyset pagination）而非 OFFSET
- [ ] 避免 N+1 查询（使用 JOIN 或批量查询）
- [ ] 大表考虑分表分库策略（水平/垂直拆分）
- [ ] 热点数据考虑加缓存层（Redis）
- [ ] 慢查询日志开启，定期分析优化
- [ ] 定期执行 ANALYZE TABLE（MySQL）/ ANALYZE（PostgreSQL）更新统计信息
- [ ] 定期清理碎片空间（MySQL: OPTIMIZE TABLE）
- [ ] 避免在大事务中持有锁时间过长
- [ ] 读写分离场景考虑只读副本
- [ ] 字段适当冗余以减少 JOIN（空间换时间，需权衡一致性）

### F.1 MySQL 连接与 CRUD（pymysql）

```python
"""
MySQL 连接与 CRUD 操作示例
依赖: pip install pymysql
"""
import pymysql
from pymysql.cursors import DictCursor
from datetime import datetime


# ========== 连接配置 ==========
DB_CONFIG = {
    "host": "127.0.0.1",
    "port": 3306,
    "user": "root",
    "password": "your_password",
    "database": "my_app",
    "charset": "utf8mb4",
    "cursorclass": DictCursor,  # 返回字典格式
}


def get_connection():
    """获取数据库连接"""
    return pymysql.connect(**DB_CONFIG)


# ========== Create ==========
def create_user(username: str, email: str, age: int) -> int:
    """插入用户，返回自增ID"""
    sql = "INSERT INTO users (username, email, age) VALUES (%s, %s, %s)"
    with get_connection() as conn:
        with conn.cursor() as cursor:
            cursor.execute(sql, (username, email, age))
        conn.commit()
        return cursor.lastrowid


def create_users_batch(users: list[dict]) -> int:
    """批量插入用户"""
    sql = "INSERT INTO users (username, email, age) VALUES (%s, %s, %s)"
    data = [(u["username"], u["email"], u["age"]) for u in users]
    with get_connection() as conn:
        with conn.cursor() as cursor:
            cursor.executemany(sql, data)
        conn.commit()
        return cursor.rowcount


# ========== Read ==========
def get_user_by_id(user_id: int) -> dict | None:
    """根据ID查询单个用户"""
    sql = "SELECT id, username, email, age, status, created_at FROM users WHERE id = %s"
    with get_connection() as conn:
        with conn.cursor() as cursor:
            cursor.execute(sql, (user_id,))
            return cursor.fetchone()


def get_users_paginated(page: int = 1, size: int = 20) -> list[dict]:
    """分页查询用户列表"""
    offset = (page - 1) * size
    sql = "SELECT id, username, email FROM users ORDER BY id LIMIT %s OFFSET %s"
    with get_connection() as conn:
        with conn.cursor() as cursor:
            cursor.execute(sql, (size, offset))
            return cursor.fetchall()


def search_users(keyword: str) -> list[dict]:
    """模糊搜索用户"""
    sql = "SELECT id, username, email FROM users WHERE username LIKE %s ORDER BY id"
    with get_connection() as conn:
        with conn.cursor() as cursor:
            cursor.execute(sql, (f"%{keyword}%",))
            return cursor.fetchall()


# ========== Update ==========
def update_user_email(user_id: int, new_email: str) -> int:
    """更新用户邮箱"""
    sql = "UPDATE users SET email = %s, updated_at = NOW() WHERE id = %s"
    with get_connection() as conn:
        with conn.cursor() as cursor:
            cursor.execute(sql, (new_email, user_id))
        conn.commit()
        return cursor.rowcount


# ========== Delete ==========
def delete_user(user_id: int) -> int:
    """删除用户"""
    sql = "DELETE FROM users WHERE id = %s"
    with get_connection() as conn:
        with conn.cursor() as cursor:
            cursor.execute(sql, (user_id,))
        conn.commit()
        return cursor.rowcount


# ========== 事务示例 ==========
def transfer_balance(from_id: int, to_id: int, amount: float) -> bool:
    """转账事务示例"""
    conn = get_connection()
    try:
        with conn.cursor() as cursor:
            # 检查余额
            cursor.execute("SELECT balance FROM users WHERE id = %s FOR UPDATE", (from_id,))
            row = cursor.fetchone()
            if not row or row["balance"] < amount:
                return False

            # 扣款
            cursor.execute(
                "UPDATE users SET balance = balance - %s WHERE id = %s",
                (amount, from_id),
            )
            # 入账
            cursor.execute(
                "UPDATE users SET balance = balance + %s WHERE id = %s",
                (amount, to_id),
            )
```

```python
                select(User).where(User.id == from_id).with_for_update()

                select(User).where(User.id == to_id).with_for_update()

            if not to_user:

            to_user.balance += amount
            session.commit()
            return True
        except Exception as e:
            session.rollback()
            print(f"[ERROR] Transfer failed: {e}")
            return False
```

```python
"""
```

```python
解决 N+1 查询问题的关键技术

from typing import Optional

from sqlalchemy import create_engine, select, String, Integer, ForeignKey

    id: Mapped[int] = mapped_column(primary_key=True, autoincrement=True)
    post_id: Mapped[int] = mapped_column(ForeignKey("posts.id"))
    content: Mapped[str]
    post: Mapped["Post"] = relationship(back_populates="comments")


DATABASE_URL = "postgresql+psycopg2://postgres:your_password@127.0.0.1:5432/my_app"
engine = create_engine(DATABASE_URL, echo=False)
SessionLocal = sessionmaker(bind=engine)


# ========== N+1 问题演示 ==========
def bad_example_n_plus_1():
    """N+1 查询问题：查 N 个用户，会产生 1+N 次查询"""
    with SessionLocal() as session:
        users = session.execute(select(User)).scalars().all()
        for user in users:
            # 每次访问 user.profile 都会触发一次额外查询
            print(f"{user.username}: {user.profile.bio if user.profile else 'No profile'}")
    # 如果有 100 个用户，会产生 1 + 100 = 101 次查询


# ========== 预加载解决方案 ==========

def eager_load_joined():
    """方案1: joinedload - JOIN 方式预加载
    适合: 一对一关系，或关联表数据量不大
    特点: 单次 SQL 查询，使用 LEFT JOIN
    """
    with SessionLocal() as session:
        stmt = select(User).options(joinedload(User.profile))
        users = session.execute(stmt).scalars().all()
        for user in users:
            print(f"{user.username}: {user.profile.bio if user.profile else 'No profile'}")
    # 只产生 1 次查询


def eager_load_selectin():
    """方案2: selectinload - IN 子查询方式预加载
    适合: 一对多关系，关联表数据量大
    特点: 2 次查询（第一次查主表，第二次用 IN 查关联表）
    优势: 不会产生 JOIN 的笛卡尔积膨胀
    """
    with SessionLocal() as session:
        stmt = select(User).options(selectinload(User.posts))
        users = session.execute(stmt).scalars().all()
        for user in users:
            print(f"{user.username}: {len(user.posts)} posts")
    # 只产生 2 次查询（不管有多少用户）


def eager_load_multi_level():
    """多层级预加载"""
    with SessionLocal() as session:
        stmt = (
            select(User)
            .options(

                .selectinload(Post.comments)

        users = session.execute(stmt).scalars().all()
        for user in users:

            for post in user.posts:
```

```python
# ========== 方式5: 重试机制（处理乐观锁冲突/序列化失败） ==========
import time

def with_retry(max_retries: int = 3, delay: float = 0.1):
    """事务重试装饰器"""
    def decorator(func):
        def wrapper(*args, **kwargs):
            for attempt in range(max_retries):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    if attempt == max_retries - 1:
                        raise
                    error_msg = str(e).lower()
                    # 检查是否是可重试的错误（序列化冲突、死锁等）
                    if "serialization" in error_msg or "deadlock" in error_msg:
                        time.sleep(delay * (attempt + 1))  # 指数退避
                        continue
                    raise
        return wrapper
    return decorator


@with_retry(max_retries=3, delay=0.1)
def update_with_retry(user_id: int, new_balance: float):
    """乐观锁 + 重试示例"""
    with get_db_session() as session:
        row = session.execute(
            text("SELECT id, balance, version FROM accounts WHERE id = :id"),
            {"id": user_id},
        ).fetchone()

        if not row:
            raise ValueError("Account not found")

        # 乐观锁: 检查版本号
        result = session.execute(
            text("""
                UPDATE accounts
                SET balance = :new_balance, version = version + 1
                WHERE id = :id AND version = :current_version
            """),
            {
                "id": user_id,
                "new_balance": new_balance,
                "current_version": row.version,
            },
        )
        if result.rowcount == 0:
            raise Exception("Optimistic lock conflict - serialization failure")
```

```python
FastAPI 数据库依赖注入模板

from datetime import datetime

from sqlalchemy.ext.asyncio import (
    AsyncSession,
    AsyncEngine,
    create_async_engine,
    async_sessionmaker,
)
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column


# ========== 模型定义 ==========
class Base(DeclarativeBase):
    pass


class User(Base):
    __tablename__ = "users"

    id: Mapped[int] = mapped_column(primary_key=True, autoincrement=True)
    username: Mapped[str] = mapped_column(String(64), unique=True, nullable=False)
    email: Mapped[str] = mapped_column(String(255), unique=True, nullable=False)
    age: Mapped[Optional[int]] = mapped_column(Integer, nullable=True)
    is_active: Mapped[bool] = mapped_column(default=True)
    created_at: Mapped[datetime] = mapped_column(default=datetime.utcnow)

from sqlalchemy import String, Integer, Boolean

# ========== 数据库配置 ==========
DATABASE_URL = "postgresql+asyncpg://postgres:your_password@127.0.0.1:5432/my_app"
# DATABASE_URL = "mysql+aiomysql://root:your_password@127.0.0.1:3306/my_app?charset=utf8mb4"

    DATABASE_URL,
    echo=False,
    pool_size=10,
    max_overflow=20,
    pool_recycle=3600,
    pool_pre_ping=True,
)

AsyncSessionLocal = async_sessionmaker(
    bind=engine,
    class_=AsyncSession,
    expire_on_commit=False,
    autocommit=False,
    autoflush=False,
)


# ========== 依赖注入 ==========
async def get_db() -> AsyncSession:
    """数据库会话依赖注入
    用法: async def endpoint(db: AsyncSession = Depends(get_db)):
    每个请求获取独立 session，请求结束自动关闭
    """
    async with AsyncSessionLocal() as session:
        try:
            yield session
        except Exception:
            await session.rollback()
            raise
        finally:
            await session.close()

    username: str
    email: EmailStr
    age: Optional[int] = None


class UserUpdate(BaseModel):
    email: Optional[EmailStr] = None
    age: Optional[int] = None

    id: int
    username: str
    email: str
    age: Optional[int]
    is_active: bool
    created_at: datetime

    class Config:
        from_attributes = True

async def startup():
    """应用启动时创建表（仅开发环境）"""
    async with engine.begin() as conn:
        await conn.run_sync(Base.metadata.create_all)


@app.on_event("shutdown")
async def shutdown():
    """应用关闭时释放连接池"""
    await engine.dispose()


# ========== 路由 ==========
@app.post("/users", response_model=UserResponse, status_code=status.HTTP_201_CREATED)
async def create_user(
    user_in: UserCreate,
    db: AsyncSession = Depends(get_db),
):
    """创建用户"""
    # 检查用户名是否已存在
    stmt = select(User).where(User.username == user_in.username)
    result = await db.execute(stmt)
    if result.scalar_one_or_none():
        raise HTTPException(
            status_code=status.HTTP_409_CONFLICT,
            detail="Username already exists",
        )

    user = User(**user_in.model_dump())
    db.add(user)
    await db.commit()
    await db.refresh(user)
    return user


@app.get("/users/{user_id}", response_model=UserResponse)
async def get_user(
    user_id: int,
    db: AsyncSession = Depends(get_db),
):
    """查询单个用户"""
    user = await db.get(User, user_id)
    if not user:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="User not found",
        )
    return user


@app.get("/users", response_model=list[UserResponse])
async def list_users(
    page: int = 1,
    size: int = 20,
    db: AsyncSession = Depends(get_db),
):
    """分页查询用户列表"""
    stmt = (
        select(User)
        .order_by(User.id)
        .limit(size)
        .offset((page - 1) * size)
    )
    result = await db.execute(stmt)
    return result.scalars().all()


@app.put("/users/{user_id}", response_model=UserResponse)
async def update_user(
    user_id: int,
    user_in: UserUpdate,
    db: AsyncSession = Depends(get_db),
):
    """更新用户"""
    user = await db.get(User, user_id)
    if not user:
        raise HTTPException(status_code=404, detail="User not found")

    update_data = user_in.model_dump(exclude_unset=True)
    for key, value in update_data.items():
        setattr(user, key, value)

    await db.commit()
    await db.refresh(user)
    return user


@app.delete("/users/{user_id}", status_code=status.HTTP_204_NO_CONTENT)
async def delete_user(
    user_id: int,
    db: AsyncSession = Depends(get_db),
):
    """删除用户"""
    user = await db.get(User, user_id)
    if not user:
        raise HTTPException(status_code=404, detail="User not found")

    await db.delete(user)
    await db.commit()


@app.get("/users/count")
async def get_user_count(db: AsyncSession = Depends(get_db)):
    """查询用户总数"""
    stmt = select(func.count(User.id))
    result = await db.execute(stmt)
```

### H.2 基本数据结构操作封装

```python
"""
Redis 基本数据结构操作封装
提供统一接口，方便业务代码使用
"""
import json
import time
from typing import Any, Optional
import redis


class RedisHelper:
    """Redis 操作封装工具类"""

    def __init__(self, redis_client: redis.Redis):
        self.r = redis_client

    # ========== String ==========
    def set_json(self, key: str, value: Any, expire: int = None) -> bool:
        """存储 JSON 对象"""
        data = json.dumps(value, ensure_ascii=False)
        return self.r.set(key, data, ex=expire)

    def get_json(self, key: str) -> Optional[Any]:
        """获取 JSON 对象"""
        data = self.r.get(key)
        if data is None:
            return None
        return json.loads(data)

    def increment(self, key: str, amount: int = 1, expire: int = None) -> int:
        """原子递增"""
        pipe = self.r.pipeline()
        pipe.incrby(key, amount)
        if expire:
            pipe.expire(key, expire)
        result = pipe.execute()
        return result[0]

    def set_if_absent(self, key: str, value: str, expire: int = 30) -> bool:
        """不存在时才设置（原子操作）"""
        return self.r.set(key, value, nx=True, ex=expire)

    # ========== Hash ==========
    def hset_json(self, key: str, field: str, value: Any) -> int:
        """哈希存储 JSON"""
        return self.r.hset(key, field, json.dumps(value, ensure_ascii=False))

    def hget_json(self, key: str, field: str) -> Optional[Any]:
        """哈希获取 JSON"""
        data = self.r.hget(key, field)
        if data is None:
            return None
        return json.loads(data)

    def hgetall_dict(self, key: str) -> dict:
        """获取整个哈希表为字典"""
        return self.r.hgetall(key)

    def hincrby(self, key: str, field: str, amount: int = 1) -> int:
        """哈希字段递增"""
        return self.r.hincrby(key, field, amount)

    # ========== List ==========
    def push_list(self, key: str, *values: str, direction: str = "left") -> int:
        """列表推入"""
        if direction == "left":
            return self.r.lpush(key, *values)
        else:
            return self.r.rpush(key, *values)

    def pop_list(self, key: str, direction: str = "left", timeout: int = 0) -> Optional[str]:
        """列表弹出"""
        if direction == "left":
            if timeout > 0:
                result = self.r.blpop(key, timeout=timeout)
                return result[1] if result else None
            return self.r.lpop(key)
        else:
            if timeout > 0:
                result = self.r.brpop(key, timeout=timeout)
                return result[1] if result else None
            return self.r.rpop(key)

    def list_page(self, key: str, page: int = 1, size: int = 20) -> list:
        """列表分页"""
        start = (page - 1) * size
        end = start + size - 1
        return self.r.lrange(key, start, end)

    # ========== Set ==========
    def sadd_members(self, key: str, *members: str) -> int:
        """集合添加"""
        return self.r.sadd(key, *members)

    def sinter_smembers(self, key1: str, key2: str) -> set:
        """集合交集"""
        return self.r.sinter(key1, key2)

    def sunion_smembers(self, key1: str, key2: str) -> set:
        """集合并集"""
        return self.r.sunion(key1, key2)

    def sdiff_smembers(self, key1: str, key2: str) -> set:
        """集合差集"""
        return self.r.sdiff(key1, key2)

    # ========== ZSet ==========
    def zadd_score(self, key: str, member: str, score: float) -> int:
        """有序集合添加"""
        return self.r.zadd(key, {member: score})

    def ztop_n(self, key: str, n: int = 10, desc: bool = True) -> list:
        """获取 Top N"""
        if desc:
            return self.r.zrevrange(key, 0, n - 1, withscores=True)
        else:
            return self.r.zrange(key, 0, n - 1, withscores=True)

    def zrank_of(self, key: str, member: str, desc: bool = True) -> Optional[int]:
        """获取成员排名"""
        if desc:
            return self.r.zrevrank(key, member)
        else:
            return self.r.zrank(key, member)

    # ========== 通用 Key 管理 ==========
    def exists(self, *keys: str) -> int:
        """检查 key 是否存在"""
        return self.r.exists(*keys)

    def delete(self, *keys: str) -> int:
        """删除 key"""
        return self.r.delete(*keys)

    def expire(self, key: str, seconds: int) -> bool:
        """设置过期时间"""
        return self.r.expire(key, seconds)

    def ttl(self, key: str) -> int:
        """查看剩余时间"""
        return self.r.ttl(key)

    def scan_iter(self, pattern: str = "*", count: int = 100):
        """安全遍历 key（使用 SCAN，不阻塞）"""
        return self.r.scan_iter(match=pattern, count=count)


# ========== 使用示例 ==========
if __name__ == "__main__":
    pool = redis.ConnectionPool(host="127.0.0.1", port=6379, decode_responses=True)
    r = redis.Redis(connection_pool=pool)
    helper = RedisHelper(r)

    # String
```

```python
class RedisDistributedLock:
    """
    Redis 分布式锁（带看门狗自动续期）

    用法1: 手动管理
        lock = RedisDistributedLock(redis_client, "lock:order:100", expire=30)
        if lock.acquire():
            try:
                # 执行业务逻辑
                pass
            finally:
                lock.release()

    用法2: 上下文管理器（推荐）
        with RedisDistributedLock(redis_client, "lock:order:100", expire=30) as lock:
            if lock.locked:
                # 执行业务逻辑
                pass
            else:
                # 获取锁失败
                pass
    """

    def __init__(
        self,
        redis_client: redis.Redis,
        lock_key: str,
        expire: int = 30,
        retry_count: int = 3,
        retry_delay: float = 0.2,
        watchdog_interval: int = 10,
    ):
        """
        :param redis_client: Redis 客户端
        :param lock_key: 锁的 key
        :param expire: 锁的过期时间（秒）
        :param retry_count: 获取锁失败时的重试次数
        :param retry_delay: 重试间隔（秒）
        :param watchdog_interval: 看门狗续期间隔（秒），应小于 expire
        """
        self.redis = redis_client
        self.lock_key = lock_key
        self.expire = expire
        self.retry_count = retry_count
        self.retry_delay = retry_delay
        self.watchdog_interval = watchdog_interval

        # 生成唯一的锁标识
        self.lock_value = str(uuid.uuid4())

        # 锁状态
        self.locked = False

        # 看门狗线程
        self._watchdog_thread: Optional[threading.Thread] = None
        self._watchdog_stop = threading.Event()

        # 注册 Lua 脚本
        self._release_script = self.redis.register_script(RELEASE_LOCK_SCRIPT)
        self._renew_script = self.redis.register_script(RENEW_LOCK_SCRIPT)

    def acquire(self, blocking: bool = True) -> bool:
        """
        获取锁
        :param blocking: 是否阻塞等待
        :return: 是否成功获取
        """
        for attempt in range(self.retry_count + 1):
            # 原子操作: SET key value NX EX expire
            result = self.redis.set(
                self.lock_key,
                self.lock_value,
                nx=True,
                ex=self.expire,
            )
            if result:
                self.locked = True
                # 启动看门狗
                self._start_watchdog()
                logger.info(f"Lock acquired: {self.lock_key}, value={self.lock_value}")
                return True

            if not blocking:
                return False

            if attempt < self.retry_count:
                logger.debug(
                    f"Lock retry {attempt + 1}/{self.retry_count} for {self.lock_key}"
                )
                time.sleep(self.retry_delay)

        logger.warning(f"Failed to acquire lock: {self.lock_key}")
        return False

    def release(self) -> bool:
        """
        释放锁（使用 Lua 脚本，确保只有持有者才能释放）
        :return: 是否成功释放
        """
        if not self.locked:
            return False

        # 停止看门狗
        self._stop_watchdog()

        # 使用 Lua 脚本安全释放
        result = self._release_script(
            keys=[self.lock_key],
            args=[self.lock_value],
        )
        self.locked = False

        if result == 1:
            logger.info(f"Lock released: {self.lock_key}")
            return True
        else:
            logger.warning(
                f"Lock already expired or not held: {self.lock_key}"
            )
            return False

    def _start_watchdog(self):
        """启动看门狗线程，自动续期"""
        self._watchdog_stop.clear()
        self._watchdog_thread = threading.Thread(
            target=self._watchdog_run,
            daemon=True,
            name=f"watchdog-{self.lock_key}",
        )
        self._watchdog_thread.start()

    def _stop_watchdog(self):
        """停止看门狗"""
        self._watchdog_stop.set()
        if self._watchdog_thread and self._watchdog_thread.is_alive():
            self._watchdog_thread.join(timeout=2)

    def _watchdog_run(self):
        """看门狗续期逻辑"""
        while not self._watchdog_stop.wait(timeout=self.watchdog_interval):
            try:
                # 使用 Lua 脚本续期
                result = self._renew_script(
                    keys=[self.lock_key],
                    args=[self.lock_value, int(self.expire * 1000)],
                )
                if result == 1:
                    logger.debug(f"Lock renewed: {self.lock_key}")
                else:
                    # 锁已丢失（可能已被其他客户端获取或已过期）
                    logger.warning(
                        f"Lock lost during renewal: {self.lock_key}"
                    )
                    break
            except Exception as e:
                logger.error(f"Watchdog error for {self.lock_key}: {e}")
                break

    def __enter__(self):
        self.acquire()
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        self.release()
        return False

    def __del__(self):
        if self.locked:
            self.release()

import redis.asyncio as aioredis

class AsyncRedisDistributedLock:
    """异步版分布式锁（使用 asyncio 实现）"""

    RELEASE_SCRIPT = """
    if redis.call('GET', KEYS[1]) == ARGV[1] then
        return redis.call('DEL', KEYS[1])
    else
        return 0
    end
    """

    RENEW_SCRIPT = """
    if redis.call('GET', KEYS[1]) == ARGV[1] then
        return redis.call('PEXPIRE', KEYS[1], ARGV[2])
    else
        return 0
    end
    """

    def __init__(
        self,
        redis_client: aioredis.Redis,
        lock_key: str,
        expire: int = 30,
        retry_count: int = 3,
        retry_delay: float = 0.2,
        watchdog_interval: int = 10,

        self.redis = redis_client
        self.lock_key = lock_key
        self.expire = expire

        self.retry_delay = retry_delay
        self.watchdog_interval = watchdog_interval
        self.lock_value = str(uuid.uuid4())
        self.locked = False
        self._watchdog_task = None
        self._release_script = self.redis.register_script(self.RELEASE_SCRIPT)
        self._renew_script = self.redis.register_script(self.RENEW_SCRIPT)

    async def acquire(self, blocking: bool = True) -> bool:
        for attempt in range(self.retry_count + 1):
            result = await self.redis.set(
                self.lock_key, self.lock_value, nx=True, ex=self.expire
            )
            if result:
                self.locked = True
                self._start_watchdog()
                return True
            if not blocking:
                return False
            if attempt < self.retry_count:
                import asyncio
                await asyncio.sleep(self.retry_delay)
        return False

    async def release(self) -> bool:
        if not self.locked:
            return False
        self._stop_watchdog()
        result = await self._release_script(
            keys=[self.lock_key], args=[self.lock_value]
        )
        self.locked = False
        return result == 1

    def _start_watchdog(self):
        import asyncio
        self._watchdog_task = asyncio.create_task(self._watchdog_run())

    def _stop_watchdog(self):
        if self._watchdog_task and not self._watchdog_task.done():
            self._watchdog_task.cancel()

    async def _watchdog_run(self):
        import asyncio
        while True:
            try:
                await asyncio.sleep(self.watchdog_interval)
                result = await self._renew_script(
                    keys=[self.lock_key],
                    args=[self.lock_value, int(self.expire * 1000)],
                )
                if result != 1:
                    break
            except asyncio.CancelledError:
                break
            except Exception:
                break

    async def __aenter__(self):
        await self.acquire()
        return self

    async def __aexit__(self, exc_type, exc_val, exc_tb):
        await self.release()
```

### H.4 缓存装饰器（@cache，支持过期时间和缓存穿透防护）

```python
"""
缓存装饰器
功能:
  1. @cache 装饰器，自动缓存函数返回值
  2. 支持设置过期时间
  3. 缓存穿透防护（空值缓存短 TTL）
  4. 缓存击穿防护（单飞机制，防止缓存失效时大量请求穿透）
  5. 支持自定义 key 生成
  6. 异步版本

依赖: pip install redis
"""
import functools
import json
import hashlib
import threading
import time
import logging
from typing import Callable, Optional, Any
import redis
import redis.asyncio as aioredis

logger = logging.getLogger(__name__)

# 空值标记，用于缓存穿透防护
NULL_MARKER = "__NULL__"


def _generate_cache_key(func: Callable, args: tuple, kwargs: dict, key_prefix: str) -> str:
    """生成缓存 key"""
    # 将函数名和参数序列化为字符串
    key_parts = [func.__module__, func.__name__]
    if args:
        key_parts.append(str(args))
    if kwargs:
        key_parts.append(str(sorted(kwargs.items())))

    raw_key = ":".join(key_parts)
    # 如果 key 太长，用 hash
    if len(raw_key) > 200:
        key_hash = hashlib.md5(raw_key.encode("utf-8")).hexdigest()
        raw_key = f"hash:{key_hash}"

    return f"{key_prefix}:{raw_key}"


def cache(
    redis_client: redis.Redis,
    expire: int = 300,
    key_prefix: str = "cache",
    null_expire: int = 60,
    enable_null_cache: bool = True,
):
    """
    同步缓存装饰器

    :param redis_client: Redis 客户端
    :param expire: 正常缓存过期时间（秒）
    :param key_prefix: 缓存 key 前缀
    :param null_expire: 空值缓存过期时间（秒），用于防穿透
    :param enable_null_cache: 是否启用空值缓存
    """
    def decorator(func: Callable) -> Callable:
        # 单飞锁: 防止缓存失效时多个线程同时回源
        _singleflight_locks = {}

        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            cache_key = _generate_cache_key(func, args, kwargs, key_prefix)

            # 1. 查缓存
            cached = redis_client.get(cache_key)
            if cached is not None:
                if cached == NULL_MARKER:
                    # 空值缓存，返回 None（防穿透）
                    return None
                return json.loads(cached)

            # 2. 缓存未命中，使用单飞机制防止缓存击穿
            lock_key = cache_key
            if lock_key not in _singleflight_locks:
                _singleflight_locks[lock_key] = threading.Lock()

            with _singleflight_locks[lock_key]:
                # double-check: 获取锁后再查一次缓存
                cached = redis_client.get(cache_key)
                if cached is not None:
                    if cached == NULL_MARKER:
                        return None
                    return json.loads(cached)

                # 3. 回源查数据库
                logger.info(f"Cache miss, calling source: {cache_key}")
                try:
                    result = func(*args, **kwargs)
                except Exception as e:
                    logger.error(f"Source call failed for {cache_key}: {e}")
                    raise

                # 4. 写入缓存
                if result is None and enable_null_cache:
                    # 空值缓存短 TTL，防止缓存穿透
                    redis_client.set(cache_key, NULL_MARKER, ex=null_expire)
                else:
                    redis_client.set(
                        cache_key,
                        json.dumps(result, ensure_ascii=False, default=str),
                        ex=expire,
                    )

                return result

        # 暴露删除缓存的方法
        def invalidate(*args, **kwargs):
            """删除指定参数的缓存"""
            cache_key = _generate_cache_key(func, args, kwargs, key_prefix)
            redis_client.delete(cache_key)
            logger.info(f"Cache invalidated: {cache_key}")

        wrapper.invalidate = invalidate
        wrapper.cache_key = lambda *a, **kw: _generate_cache_key(func, a, kw, key_prefix)

        return wrapper

    return decorator


def async_cache(
    redis_client: aioredis.Redis,
    expire: int = 300,
    key_prefix: str = "cache",
    null_expire: int = 60,
    enable_null_cache: bool = True,
):
    """
    异步缓存装饰器
    """
    import asyncio

    def decorator(func: Callable) -> Callable:
        _singleflight_locks: dict[str, asyncio.Lock] = {}
        _locks_lock = asyncio.Lock()

        async def _get_lock(key: str) -> asyncio.Lock:
            async with _locks_lock:
                if key not in _singleflight_locks:
                    _singleflight_locks[key] = asyncio.Lock()
                return _singleflight_locks[key]

        @functools.wraps(func)
        async def wrapper(*args, **kwargs):
            cache_key = _generate_cache_key(func, args, kwargs, key_prefix)

            # 1. 查缓存
            cached = await redis_client.get(cache_key)
            if cached is not None:
                if cached == NULL_MARKER:
                    return None
                return json.loads(cached)

            # 2. 单飞机制
            lock = await _get_lock(cache_key)
            async with lock:
                cached = await redis_client.get(cache_key)
                if cached is not None:
                    if cached == NULL_MARKER:
                        return None
                    return json.loads(cached)

                # 3. 回源
                result = await func(*args, **kwargs)

                # 4. 写缓存
                if result is None and enable_null_cache:
                    await redis_client.set(cache_key, NULL_MARKER, ex=null_expire)
                else:
                    await redis_client.set(
                        cache_key,
                        json.dumps(result, ensure_ascii=False, default=str),
                        ex=expire,
                    )
                return result

        async def _invalidate(*args, **kwargs):
            cache_key = _generate_cache_key(func, args, kwargs, key_prefix)
            await redis_client.delete(cache_key)

        wrapper.invalidate = _invalidate
        return wrapper

    return decorator


# ========== 使用示例 ==========
if __name__ == "__main__":
    pool = redis.ConnectionPool(host="127.0.0.1", port=6379, decode_responses=True)
    r = redis.Redis(connection_pool=pool)

    # 同步缓存示例
    @cache(r, expire=300, key_prefix="user")
    def get_user(user_id: int):
        """模拟从数据库查用户"""
        print(f"  [DB] Querying user {user_id}...")
        # 模拟数据库查询
        if user_id <= 0:
            return None
        return {"id": user_id, "name": f"user_{user_id}", "age": 25}

    # 第一次调用: 缓存未命中，查数据库
    print("Call 1:", get_user(1))

    # 第二次调用: 命中缓存
    print("Call 2:", get_user(1))

    # 不存在的用户: 空值缓存
    print("Call 3:", get_user(-1))
    print("Call 4:", get_user(-1))  # 命中空值缓存

    # 失效缓存
    get_user.invalidate(1)
    print("Call 5:", get_user(1))  # 再次查数据库
```

### H.5 限流器实现（令牌桶）

```python
"""
基于 Redis 的令牌桶限流器
功能:
  1. 原子令牌桶算法（Lua 脚本保证操作原子性）
  2. 支持同步和异步
  3. 装饰器模式使用
  4. 支持不同粒度限流（IP/用户/接口）

依赖: pip install redis
"""
import time
import functools
import logging
from typing import Optional
import redis
import redis.asyncio as aioredis

logger = logging.getLogger(__name__)


# 令牌桶 Lua 脚本（原子操作）
TOKEN_BUCKET_LUA = """
local key = KEYS[1]
local capacity = tonumber(ARGV[1])
local refill_rate = tonumber(ARGV[2])  -- tokens per second
local now = tonumber(ARGV[3])
local requested = tonumber(ARGV[4])

-- 获取当前桶状态
local bucket = redis.call('HMGET', key, 'tokens', 'last_time')
local tokens = tonumber(bucket[1])
local last_time = tonumber(bucket[2])

-- 初始化桶
if tokens == nil then
    tokens = capacity
    last_time = now
end

-- 计算需要补充的令牌
local elapsed = math.max(0, now - last_time)
local refill = elapsed * refill_rate
tokens = math.min(capacity, tokens + refill)

-- 尝试消费令牌
local allowed = 0
if tokens >= requested then
    tokens = tokens - requested
    allowed = 1
end

-- 更新桶状态
redis.call('HMSET', key, 'tokens', tokens, 'last_time', now)
redis.call('EXPIRE', key, math.ceil(capacity / refill_rate * 2))

return allowed
"""


class TokenBucketRateLimiter:
    """
    令牌桶限流器

    用法1: 直接调用
        limiter = TokenBucketRateLimiter(redis_client, capacity=10, refill_rate=1)
        if limiter.is_allowed("user:123"):
            # 允许请求
        else:
            # 限流

    用法2: 装饰器
        @TokenBucketRateLimiter.decorate(redis_client, capacity=10, refill_rate=1)
        def my_api(user_id: int):
            ...
    """

    def __init__(
        self,
        redis_client: redis.Redis,
        capacity: int = 10,
        refill_rate: float = 1.0,
    ):
        """
        :param capacity: 桶容量（最大突发请求数）
        :param refill_rate: 令牌填充速率（个/秒）
        """
        self.redis = redis_client
        self.capacity = capacity
        self.refill_rate = refill_rate
        self._script = self.redis.register_script(TOKEN_BUCKET_LUA)

    def is_allowed(self, identifier: str, tokens: int = 1) -> bool:
        """
        检查是否允许请求
        :param identifier: 限流标识（如 user_id、IP）
        :param tokens: 需要消费的令牌数
        :return: 是否允许
        """
        key = f"rate_limit:{identifier}"
        now = time.time()
        result = self._script(
            keys=[key],
            args=[self.capacity, self.refill_rate, now, tokens],
        )
        return result == 1

    @classmethod
    def decorate(
        cls,
        redis_client: redis.Redis,
        capacity: int = 10,
        refill_rate: float = 1.0,
        key_func: Optional[callable] = None,
    ):
        """
        限流装饰器

        :param key_func: 返回限流标识的函数，默认用第一个参数
        """
        limiter = cls(redis_client, capacity, refill_rate)

        def decorator(func):
            @functools.wraps(func)
            def wrapper(*args, **kwargs):
                if key_func:
                    identifier = key_func(*args, **kwargs)
                elif args:
                    identifier = str(args[0])
                else:
                    identifier = "default"

                if not limiter.is_allowed(identifier):
                    logger.warning(f"Rate limited: {identifier}")
                    raise RuntimeError(f"Rate limit exceeded for {identifier}")

                return func(*args, **kwargs)

            return wrapper

        return decorator
```

### H.6 会话管理封装

```python
"""
Redis 会话管理封装
功能:
  1. 创建/获取/删除会话
  2. 自动过期
  3. 会话续期
  4. 支持存储任意 JSON 数据
  5. 支持同步和异步

依赖: pip install redis
"""
import json
import uuid
import time
from typing import Optional, Any
import redis
import redis.asyncio as aioredis


class SessionManager:
    """
    会话管理器

    用法:
        session_mgr = SessionManager(redis_client, prefix="session", expire=3600)

        # 创建会话
        session_id = session_mgr.create({"user_id": 1, "username": "alice"})

        data = session_mgr.get(session_id)

            print(data["user_id"])

    """

    def __init__(
        self,
        redis_client: redis.Redis,
        prefix: str = "session",
        expire: int = 3600,
    ):
        """
        :param prefix: key 前缀
        :param expire: 默认过期时间（秒）
        """
        self.redis = redis_client
        self.prefix = prefix
        self.expire = expire

    def _key(self, session_id: str) -> str:
        return f"{self.prefix}:{session_id}"

    def create(
        self,
        data: dict,
        session_id: str = None,
        expire: int = None,
    ) -> str:
        """创建会话"""
        if session_id is None:
            session_id = uuid.uuid4().hex

        key = self._key(session_id)
        session_data = {
            **data,
            "_created_at": int(time.time()),
            "_expire_at": int(time.time()) + (expire or self.expire),
        }

        self.redis.set(
            key,
            json.dumps(session_data, ensure_ascii=False),
            ex=expire or self.expire,
        )
        return session_id

    def get(self, session_id: str) -> Optional[dict]:
        """获取会话数据"""
        key = self._key(session_id)
        data = self.redis.get(key)
        if data is None:
            return None
        return json.loads(data)

    def update(self, session_id: str, data: dict) -> bool:
        """更新会话数据（合并）"""
        existing = self.get(session_id)
        if existing is None:
            return False

        existing.update(data)
        ttl = self.redis.ttl(self._key(session_id))
        if ttl < 0:
            ttl = self.expire

        self.redis.set(
            self._key(session_id),
            json.dumps(existing, ensure_ascii=False),
            ex=ttl,
        )
        return True

    def refresh(self, session_id: str, expire: int = None) -> bool:
        """续期会话"""
        key = self._key(session_id)
        if not self.redis.exists(key):
            return False
        return self.redis.expire(key, expire or self.expire)

    def destroy(self, session_id: str) -> bool:
        """销毁会话"""
        return self.redis.delete(self._key(session_id)) > 0

    def exists(self, session_id: str) -> bool:
        """检查会话是否存在"""
        return self.redis.exists(self._key(session_id)) > 0
```

### H.7 计数器与排行榜封装

```python
"""
Redis 计数器与排行榜封装
功能:
  1. 原子计数器（支持日/周/月维度）
  2. 排行榜（ZSet 实现，支持分数更新、排名查询）
  3. 支持同步和异步

依赖: pip install redis
"""
import time
from datetime import datetime, timedelta
from typing import Optional
import redis
import redis.asyncio as aioredis


class Counter:
    """
    原子计数器
    支持按时间维度（日/周/月）计数，自动过期

    用法:
        counter = Counter(redis_client)
        counter.incr("page_views", "home")          # 今日浏览量 +1
        counter.incr("page_views", "home", amount=5) # 今日浏览量 +5
        counter.get("page_views", "home")            # 获取今日浏览量
        counter.get_total("page_views", "home")      # 获取总浏览量（不带日期）
    """

    def __init__(self, redis_client: redis.Redis, prefix: str = "counter"):
        self.redis = redis_client
        self.prefix = prefix

    def _key(self, name: str, identifier: str, date_suffix: str = None) -> str:
        if date_suffix is None:
            date_suffix = datetime.now().strftime("%Y%m%d")
        return f"{self.prefix}:{name}:{identifier}:{date_suffix}"

    def incr(self, name: str, identifier: str, amount: int = 1, expire: int = 86400 * 7) -> int:
        """递增计数器（按日期维度）"""
        key = self._key(name, identifier)
        pipe = self.redis.pipeline()
        pipe.incrby(key, amount)
        pipe.expire(key, expire)
        result = pipe.execute()
        return result[0]

    def get(self, name: str, identifier: str, date_suffix: str = None) -> int:
        """获取计数（默认今日）"""
        key = self._key(name, identifier, date_suffix)
        val = self.redis.get(key)
        return int(val) if val else 0

    def get_range(self, name: str, identifier: str, days: int = 7) -> dict:
        """获取最近 N 天的计数"""
        result = {}
        today = datetime.now()
        for i in range(days):
            date = today - timedelta(days=i)
            date_suffix = date.strftime("%Y%m%d")
            result[date_suffix] = self.get(name, identifier, date_suffix)
        return result

    def incr_total(self, name: str, identifier: str, amount: int = 1) -> int:
        """递增总计数器（不按日期，不过期）"""
        key = f"{self.prefix}:{name}:{identifier}:total"
        return self.redis.incrby(key, amount)

    def get_total(self, name: str, identifier: str) -> int:
        """获取总计数"""
        key = f"{self.prefix}:{name}:{identifier}:total"
        val = self.redis.get(key)
        return int(val) if val else 0


class Leaderboard:
    """
    排行榜（基于 ZSet）
    支持分数更新、排名查询、Top N 获取

    用法:
        lb = Leaderboard(redis_client, "game_scores")
        lb.add_score("alice", 100)
        lb.add_score("bob", 90)
        lb.add_score("alice", 50)  # alice 累计 150
        lb.get_top_n(10)  # Top 10
        lb.get_rank("alice")  # alice 的排名
    """

    def __init__(self, redis_client: redis.Redis, name: str):
        self.redis = redis_client
        self.name = name
        self.key = f"leaderboard:{name}"

    def add_score(self, member: str, score: float, increment: bool = True) -> float:
        """添加/更新分数"""
        if increment:
            return self.redis.zincrby(self.key, score, member)
        else:
            self.redis.zadd(self.key, {member: score})
            return score

    def get_score(self, member: str) -> Optional[float]:
        """获取成员分数"""
        score = self.redis.zscore(self.key, member)
        return float(score) if score is not None else None

    def get_rank(self, member: str, desc: bool = True) -> Optional[int]:
        """获取成员排名（0 开始）"""
        if desc:
            rank = self.redis.zrevrank(self.key, member)
        else:
            rank = self.redis.zrank(self.key, member)
        return int(rank) if rank is not None else None

    def get_top_n(self, n: int = 10, with_scores: bool = True) -> list:
        """获取 Top N"""
        return self.redis.zrevrange(self.key, 0, n - 1, withscores=with_scores)

    def get_around(self, member: str, count: int = 2) -> list:
        """获取指定成员附近的排名（含自己）"""
        rank = self.get_rank(member)
        if rank is None:
            return []
        start = max(0, rank - count)
        end = rank + count
        return self.redis.zrevrange(self.key, start, end, withscores=True)

    def remove(self, member: str) -> bool:
        """移除成员"""
        return self.redis.zrem(self.key, member) > 0

    def total_members(self) -> int:
        """总成员数"""
        return self.redis.zcard(self.key)

    def get_page(self, page: int = 1, size: int = 20) -> list:
        """分页获取"""
        start = (page - 1) * size
        end = start + size - 1
        return self.redis.zrevrange(self.key, start, end, withscores=True)


# ========== 使用示例 ==========
if __name__ == "__main__":
    pool = redis.ConnectionPool(host="127.0.0.1", port=6379, decode_responses=True)
    r = redis.Redis(connection_pool=pool)

    # 计数器示例
    counter = Counter(r)
    counter.incr("page_views", "home_page")
    counter.incr("page_views", "home_page", amount=5)
    print(f"Today's views: {counter.get('page_views', 'home_page')}")
    print(f"Total views: {counter.get_total('page_views', 'home_page')}")
    print(f"Last 7 days: {counter.get_range('page_views', 'home_page', 7)}")

    # 排行榜示例
    lb = Leaderboard(r, "game_scores")
    lb.add_score("alice", 100)
    lb.add_score("bob", 90)
    lb.add_score("carol", 110)
    lb.add_score("dave", 85)
    lb.add_score("eve", 120)

    print("\n--- Leaderboard Top 5 ---")
    for member, score in lb.get_top_n(5):
        print(f"  {member}: {score:.0f}")

    print(f"\nAlice's score: {lb.get_score('alice')}")
    print(f"Alice's rank: {lb.get_rank('alice')}")
    print(f"Total members: {lb.total_members()}")

    print("\n--- Around Alice ---")
    for member, score in lb.get_around("alice", count=1):
        print(f"  {member}: {score:.0f}")
```

```python
def async_cache_decorator(expire: int = 300, key_prefix: str = "api_cache"):
    """异步缓存装饰器"""
    def decorator(func):
        async def wrapper(*args, request: Request = None, **kwargs):
            r = RedisManager.get_client()
            # 生成缓存 key
            cache_key = f"{key_prefix}:{request.url.path}:{hash(str(kwargs))}"

            # 查缓存
            cached = await r.get(cache_key)
            if cached:
                return json.loads(cached)

            # 执行函数
            result = await func(*args, request=request, **kwargs)

            # 写缓存
            if result:
                await r.set(cache_key, json.dumps(result, default=str), ex=expire)

            return result
        return wrapper
    return decorator


# ========== 限流器（异步） ==========
async def rate_limit(identifier: str, limit: int = 10, window: int = 60) -> bool:
    """滑动窗口限流"""
    r = RedisManager.get_client()
    key = f"rate_limit:{identifier}"
    now = time.time()
    pipe = r.pipeline()
    pipe.zremrangebyscore(key, 0, now - window)
    pipe.zadd(key, {str(now): now})
    pipe.zcount(key, now - window, now)
    pipe.expire(key, window)
    results = await pipe.execute()
    count = results[2]
    return count <= limit
```

```
                                     |             |

                                     |             |
                               [一致性要求?]  [一致性要求?]
                                     |             |
                              +------+------+ +----+----+
                              |           | |         |
                          最终一致    强一致  最终一致   强一致
                              |           | |         |
                         Redis锁    Redis锁+  Redis锁  ZooKeeper
                         (SET NX)   DB事务   (SET NX)  分布式锁
                                    (最终    +看门狗)  (强一致
                                     一致)             CP模型)
```

### I.3 四种锁方案对比总结

| 对比维度 | 数据库行锁 (SELECT FOR UPDATE) | 数据库乐观锁 (version 字段) | Redis 分布式锁 (SET NX EX) | ZooKeeper 分布式锁 |
|---------|------|------|------|------|
| **实现方式** | SQL: `SELECT ... FOR UPDATE` | 表加 version 字段，UPDATE 时检查 | `SET key val NX EX` + Lua 释放 | 创建临时顺序节点 + Watch |
| **一致性保证** | 强一致（数据库事务保证） | 最终一致（冲突时需重试） | 最终一致（AP 模型，依赖 TTL） | 强一致（CP 模型，ZAB 协议） |
| **性能** | 中等（持有数据库连接和锁） | 高（无锁竞争，冲突时重试） | 高（内存操作，延迟低） | 较低（需要集群共识协议） |
| **适用并发量** | < 1000 QPS | < 500 QPS（冲突少时更优） | 1000-10000 QPS | 1000-5000 QPS |
| **锁粒度** | 行级（精确到单行） | 行级（通过 version 字段） | key 级（自定义粒度） | 节点级（自定义路径） |
| **是否跨服务** | 否（仅限同一数据库） | 否（仅限同一数据库） | 是（跨服务跨实例） | 是（跨服务跨实例） |
| **锁超时处理** | 事务超时或连接断开自动释放 | 无超时问题（每次 UPDATE 检查） | TTL 过期自动释放 + 看门狗续期 | 会话断开临时节点自动删除 |
| **死锁风险** | 有（需设置锁等待超时） | 无（无锁等待） | 低（TTL 兜底） | 无（临时节点 + Watch 机制） |
| **可用性** | 依赖数据库可用性 | 依赖数据库可用性 | 依赖 Redis 可用性（可配哨兵/集群） | 依赖 ZK 集群可用性（需多数派存活） |
| **实现复杂度** | 低（一条 SQL） | 低（加字段 + CAS 逻辑） | 中（需看门狗续期 + Lua 安全释放） | 高（需理解 ZK API + 临时顺序节点） |
| **故障恢复** | 数据库崩溃则锁释放 | 无需恢复 | Redis 崩溃锁自动释放（TTL） | ZK 会话断开锁自动释放 |
| **适用场景** | 同库事务内行级锁、订单扣库存、资金转账 | 冲突少的并发更新、CMS 内容编辑、用户信息更新 | 跨服务分布式锁、限流、防重复提交、缓存击穿防护 | 需要强一致的分布式锁、Leader 选举、配置分发 |
| **优点** | 简单直接，事务保证强，无需额外组件 | 无锁无等待，性能高，无死锁风险 | 性能高，实现灵活，社区成熟 | 强一致保证，可靠性最高，自动故障恢复 |
| **缺点** | 持有数据库连接，性能瓶颈，死锁风险 | 冲突多时重试开销大，不适合高冲突场景 | 有锁过期风险（需看门狗），时钟漂移问题 | 性能较低，部署运维复杂，实现复杂 |

### I.4 选型建议总结

```
+--------------------------------------------------------------------------+
|                         快速选型建议                                       |
+--------------------------------------------------------------------------+
|                                                                          |
|  场景1: 单服务，同一数据库内并发控制                                       |
|  --> 数据库行锁 (SELECT FOR UPDATE)                                       |

|                                                                          |

|  --> 并发 < 1000 QPS: Redis 分布式锁 (SET NX EX + 看门狗)                |
|  --> 并发 >= 1000 QPS 且最终一致可接受: Redis 分布式锁                     |
|  --> 并发 >= 1000 QPS 且强一致要求极高: ZooKeeper                         |
|                                                                          |
|  场景3: 防缓存击穿/防重复提交                                             |
|  --> Redis 分布式锁 (简单 SET NX EX 即可)                                |
|                                                                          |
|  场景4: 库存扣减/秒杀                                                     |
|  --> 低并发: 数据库行锁                                                   |
|  --> 高并发: Redis 预扣减 + 数据库最终一致                                 |
|  --> 超高并发: Redis Lua 原子扣减 + 异步落库                              |
|                                                                          |
|  场景5: 定时任务防重复执行                                                |
|  --> Redis 分布式锁 (SET NX EX，执行完 DEL)                               |
|                                                                          |
|  场景6: 分布式 Leader 选举                                                 |
|  --> ZooKeeper 或 etcd（强一致需求）                                      |
|  --> Redis（最终一致可接受时）                                             |
|                                                                          |
+--------------------------------------------------------------------------+
```

### I.5 Redis 分布式锁的注意事项

```
Redis 分布式锁的坑和最佳实践:

1. 锁超时问题
   - 问题: 业务执行时间超过锁 TTL，锁自动释放，其他客户端获取锁，导致并发
   - 解决: 使用看门狗（Watchdog）自动续期（参见附录 H.3）

2. 锁误删问题
   - 问题: 客户端 A 的锁过期后，客户端 B 获取锁；此时 A 执行完毕释放锁，
           删除了 B 的锁
   - 解决: 锁值使用唯一标识（UUID），释放时用 Lua 脚本检查后再删

3. Redis 主从切换丢锁
   - 问题: 主节点加锁后未同步到从节点就宕机，从节点升级后锁丢失
   - 解决: 使用 RedLock 算法（多节点加锁，多数成功才算成功）
   - 注意: RedLock 有争议（Martin Kleppmann vs antirez 的争论），
           建议根据一致性需求决定

4. 时钟漂移
   - 问题: Redis 服务器和客户端时钟不同步，导致 TTL 计算不准
   - 解决: TTL 设置留足余量，配合看门狗续期

5. 网络分区
   - 问题: 客户端持锁期间网络分区，Redis 认为锁已过期但客户端不知道
   - 解决: 业务层加幂等检查（即使锁失效，操作本身也是幂等的）

最佳实践总结:
  SET key value NX EX 30          -- 原子加锁，带 TTL
  + 唯一标识 (UUID)                -- 防止误删
  + Lua 脚本释放                   -- 安全释放
  + 看门狗续期                      -- 防止超时
  + 业务幂等                        -- 兜底防护
  = 可靠的 Redis 分布式锁
```
